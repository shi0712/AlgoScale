# Inverted 题解

## 1. 先把不断变化的图还原成原树上的计数

设已操作点集为 $S$，未操作点集为 $U$。题目只操作 $n-1$ 个不同点，所以 $U$ 始终非空。

定义 $F(U)$ 为原树中满足以下条件的生成森林数量：每个连通块恰好包含一个 $U$ 中的点。再设 $c(U)$ 为原树在 $U$ 上诱导出的森林连通块数。

关键公式是

$$\boxed{\text{当前图生成树数}=2^{c(U)-1}F(U).}$$

### 公式证明

一条原树边，若两端都未操作，就只对应一条边；否则对应两条边。当前图的一棵生成树必须从每条原树边的对应边中至少选一条，否则原树切开的两侧不连通。

当前图有 $n+|S|$ 个顶点，生成树有 $n+|S|-1$ 条边，所以恰好有 $|S|$ 条原树边的两个对应边都被选中。将这些原树边记为 $H$，它在原点集上形成 $|U|$ 个连通块。

若某块含两个未操作点，连接它们的路径被双份选中，两端未被复制的顶点将两份路径闭合成环，矛盾。因此每块至多含一个 $U$ 点；块数又为 $|U|$，所以每块恰含一个。

反过来，对这样一个块，沿其唯一的未操作点向外看，所有已操作点有两份副本，双份树边将它们连成一棵树。不同块之间再各选一条原树边的对应边，整体仍连通且边数正确。

$H$ 外有 $|U|-1$ 条原树边。其中两端都在 $U$ 的边只能选原边，其他边均有两种选择。设未操作点之间的边数为 $e_U$，则 $c(U)=|U|-e_U$，可二选一的边数为 $|U|-1-e_U=c(U)-1$，公式得证。

## 2. 森林计数的二状态树 DP

将原树根设为 $1$。定义 $f_0(u),f_1(u)$：在 $u$ 子树内选森林，所有不含 $u$ 的连通块均恰含一个未操作点，而含 $u$ 的块分别含零个、一个未操作点。

最终 $F(U)=f_1(1)$。令

$$X_u=f_0(u)+f_1(u),\qquad Y_u=f_1(u).$$

对于儿子集合，定义

$$A=\prod_vX_v,\qquad B=\sum_vY_v\prod_{w\ne v}X_w.$$

一个儿子的根块若含零个未操作点，必须连接到 $u$；若含一个，可以断开并独立成为合法块。要把一个未操作点通过儿子带入 $u$ 的块，至多选择一个儿子，因此得到 $B$。

于是

$$u\in U:\quad(X_u,Y_u)=(A,A),$$

$$u\notin U:\quad(X_u,Y_u)=(A+B,B).$$

两组儿子的信息可以按结合律合并：

$$(A_1,B_1)\odot(A_2,B_2)=(A_1A_2,B_1A_2+A_1B_2),$$

单位元为 $(1,0)$。整个转移不使用除法，模数下某个乘积为零也不会影响维护。

## 3. 将重链上的递推写成矩阵

选子树最大的儿子 $h$ 为重儿子，只合并轻儿子，得到 $(A,B)$。包含重儿子后的两项为

$$A_{\text{all}}=AX_h,\qquad B_{\text{all}}=BX_h+AY_h.$$

因此

$$\begin{pmatrix}X_u\\Y_u\end{pmatrix}=M_u\begin{pmatrix}X_h\\Y_h\end{pmatrix},$$

其中

$$M_u=\begin{cases}
\begin{pmatrix}A&0\\A&0\end{pmatrix},&u\in U,\\[4pt]
\begin{pmatrix}A+B&A\\B&A\end{pmatrix},&u\notin U.
\end{cases}$$

一条重链的贡献就是从上到下的矩阵乘积，再乘空重儿子的向量 $(1,0)^T$。

普通的“每条重链建线段树”容易得到每次 $O(\log^2n)$。为了达到标程的 $O(\log n)$ 更新，需要进一步控制表达式的整体高度。

## 4. 按子树大小建立平衡表达式树

整个 DP 只含两种结合运算：轻儿子信息的 $\odot$，以及重链矩阵乘法。可以预先把这些运算组织成一棵静态表达式树。

对重链上的节点 $u$，定义权重

$$w(u)=\operatorname{sz}(u)-\operatorname{sz}(h(u))
=1+\sum_{v\text{ 为轻儿子}}\operatorname{sz}(v).$$

一条链按 $w(u)$ 的带权中位数递归分割。对同一个点的轻儿子集合，则按各儿子的子树大小作带权中位数分割，用 $\odot$ 合并。

为什么总高度是 $O(\log n)$？在总权重 $W$ 的区间中，权重为 $w$ 的元素深度为 $O(1+\log(W/w))$。从一条重链进入某节点的轻儿子 $v$ 时，两段深度相加为

$$O\left(1+\log\frac{\operatorname{sz}(\text{链首})}{w(u)}+\log\frac{w(u)}{\operatorname{sz}(v)}\right)
=O\left(1+\log\frac{\operatorname{sz}(\text{链首})}{\operatorname{sz}(v)}\right).$$

沿路径累加，这些比值的对数相消。又因为每条轻边至少使子树大小减半，跨轻边次数也为 $O(\log n)$。因此整棵表达式树高度为 $O(\log n)$。

修改一个点的状态时，只改变该点的局部矩阵，然后沿表达式树的父链重新计算，每层常数次模乘加即可。根表达式矩阵的第一列给出原树根的 $(X,Y)$，其中 $Y=F(U)$。

## 5. 维护因子 $2^{c(U)-1}$

初始所有点未操作，$c(U)=1$。操作点 $x$ 前，数出它有多少个邻点仍未操作，记为 $d$。在森林中删除一个度数为 $d$ 的点，连通块数变化为 $d-1$，所以

$$c(U)-1\leftarrow c(U)-1+d-1.$$

每点只操作一次，直接扫描它的邻接表统计即可；所有操作的扫描总量为 $O(n)$。预处理 $2^0,2^1,\ldots,2^n$，每次输出对应二次幂乘根 DP 值。

## 正确性与复杂度

生成树到双选边森林的对应给出计数公式；二状态 DP 无重无漏地枚举每块恰含一个未操作点的森林；表达式树只改变结合次序，不改变转移；连通块数按森林删点公式更新。因此每次输出都是当前图的生成树数。

表达式节点数为 $O(n)$，每次更新为 $O(\log n)$，总复杂度为

$$\boxed{O(n\log(n+1))\text{ 时间},\quad O(n)\text{ 空间}.}$$

原树的遍历与子树大小计算采用迭代方式，避免长链深递归；表达式构造只需对数深度。矩阵乘法顺序不能交换。$n=1$ 时没有操作，也不输出任何一行。
