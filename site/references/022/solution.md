# 《双列对决》题解

来源：[题目](https://qoj.ac/problem/10103)、[讨论 2639](https://qoj.ac/problem/10103/discussion/2639)、[讨论引用的公开实现](https://qoj.ac/submission/2936508)。本文是对该做法的推导和独立核查，不将其重新宣称为原创。

记 $K=k+1$。标准程序使用讨论中的多项式状态消元和对角线递推，真实时间复杂度为 $O((n+m)K)$，空间为 $O(n+m+k)$，全部答案现场计算。题目允许 $k=0$，所以完整写法应保留 $k+1$。

本改编版范围为 $1\le n,m\le10^6$、$0\le k\le5000$、$(n+m)(k+1)\le10^8$，棋子点数属于 $[1,10^5]$，概率模 $998244353$。原题的 $n,m\le1000,k\le20$ 已扩大，下面给出扩大范围所需的整数界核查。该算法来自公开讨论，不宣称原创、理论最优或全局最优。

算法有两步：用保持不变的线性关系消去一个炸弹状态，再把同值棋子的二维计数转移化成一条对角线上的递推。

## 一、普通棋子的对局只需要后缀最大值

对序列 $S$，从右往左保留所有不小于已扫描最大值的元素，再恢复原顺序，记为 $f(S)$。相等的最大值必须全部保留。例如

$$f(5,3,2,4,5,3,4,2,1)=(5,5,4,2,1).$$

没有炸弹时，胜负等于 $f(A),f(B)$ 的字典序比较，空序列小于任意非空序列。

按最大值递归即可证明：最大值较大的一方会有棋子存活；最大值相等时，它们会相互抵消，数量较多的一方获胜；最大值及数量均相等时，双方最后一个最大值同时被消耗，继续比较其后的后缀。最大值以前的更小元素不决定最终胜负。

## 二、只计算 Y 胜和平局，唯一地切分炸弹对应的段

X 有 $k$ 枚炸弹，Y 没有炸弹。若结果是 Y 胜或平局，X 的全部炸弹必然被消耗，每枚炸弹都唯一对应一个被它炸掉的 Y 棋子 $C$。

按炸弹切分 X，并按这些对应的 $C$ 切分 Y，得到 $k$ 对“炸弹前的普通段”，以及最后一对普通段。对某个炸弹前的普通段 $A,B$，合法条件是

$$f(A)=f(B),\qquad\text{或}\qquad f(B)<f(A)<f(B+C).$$

第一种是 A、B 同时打完，炸弹接着遇到 C；第二种是 A 先打完 B，再被 C 打完，最后炸弹遇到 C。上界必须严格，否则 C 会被普通棋子抵消，便不是该炸弹的匹配对象。

从大到小处理普通棋子的点数。每个炸弹段只需区分：

| 状态 | 含义 | 标记 |
|---|---|---|
| U | 对应的 C 尚未加入；当前两个普通段必须平局 | $\xi$ |
| T | C 已加入，前面的两个普通段仍然平局 | $\eta$ |
| F | C 已加入，前面普通段已经确定 X 胜，但 C 能打败 X 的剩余普通棋子 | $1$ |

最后一个段若仍平局标记为 $\tau$，若已确定 Y 胜则权为 $1$；确定 X 胜的最后段不计入当前计数。初始多项式为 $\xi^k\tau$。

“当前已确定胜负”是指在已经处理的较大点数上已出现字典序差异；继续插入较小点数不会推翻这个差异。

## 三、生成函数的三个替换从哪里来

设此前已加入 X 普通棋子 $A$ 枚、Y 棋子 $B$ 枚。Y 的 $B$ 包括已经作为 C 的棋子。令

$$a=A+K,\qquad b=B+1.$$

本轮用 $u,v$ 分别记录新加入的 X、Y 棋子数。小点数插在较大棋子之前不影响后缀最大值，因而每个自由空隙贡献 $1/(1-u)$ 或 $1/(1-v)$。

若当前有 $i$ 个 U 段，Y 的已指定 C 有 $k-i$ 枚。移除这些作为分隔符的 C 后，Y 的普通片段总自由空隙数是

$$B-(k-i)+K=B+i+1.$$

X 的自由空隙数是 $A+K$。因此可提出公共因子

$$W=(1-u)^{-a}(1-v)^{-b},$$

把 Y 多出的 $i$ 个自由空隙分别计入 U 的局部替换。这解释了为什么公共指数是 $B+1$，而不是直接写成 $B+K$。

尚未分出胜负的普通段，末尾加入的当前点数才会改变状态。双方末尾加入同样多枚时，贡献 $1/(1-uv)$；X 比 Y 多至少一枚时，贡献 $u/((1-u)(1-uv))$；Y 更多时对称。

由此得到

$$
\xi\mapsto\xi'=\frac{(1-u)(\xi+v\eta)}{1-uv},
$$

$$
\eta\mapsto\eta'=\frac{(1-v)((1-u)\eta+u)}{1-uv},
$$

$$
\tau\mapsto\tau'=\frac{(1-u)((1-v)\tau+v)}{1-uv}.
$$

U 可以继续等待 C，或者选一枚当前点数作 C，此时增加一个 $v$ 并转成 T。它不能直接转成 F：当前点数若使 X 普通段领先，会把同值 C 先消耗掉。

T 可以继续平局，或者让 X 末尾多放当前点数而转成 F。这里 C 是此前加入的更大点数，所以仍能打败这段。最后一段则允许 Y 末尾更多，从平局转成 Y 胜。已经确定的合法段可以自由插入更小棋子，局部权保持为 $1$。

## 四、第一个优化：不变量消元，再只存一个多项式

直接维护 U、T 的数量会有 $O(k^2)$ 个状态。但三个替换满足

$$\xi'+\eta'-1=\frac{1-u}{1-uv}(\xi+\eta-1).$$

最终要求所有炸弹都找到匹配对象，恰好是代入 $\xi=0,\eta=1$。这个终点属于 $\xi+\eta=1$，而该关系在转移下保持不变，所以可以从一开始就令

$$\eta=1-\xi.$$

更严格地说，两个多项式如果相差 $(\xi+\eta-1)$ 的倍数，经过替换、乘公共因子和取 $[u^pv^q]$ 后仍相差其倍数，最终求值相同。因而这是合法消元，不是对二维状态的近似。

令 $\xi=x,\tau=t$，消元后两者都执行同一个仿射替换

$$\phi(z)=\frac{(1-u)((1-v)z+v)}{1-uv}=\lambda z+\mu.$$

初始 $G(x,t)=x^{K-1}t$，且始终可以写成

$$\boxed{G(x,t)=R(x)+\frac{t-x}{K}R'(x)},\qquad\deg R\le K.$$

初始 $R(x)=x^K$ 即可得到该式。保持性的证明只有链式法则：

$$\phi(t)-\phi(x)=\lambda(t-x),\qquad\frac{d}{dx}R(\phi(x))=\lambda R'(\phi(x)).$$

再乘 W、取系数，仍保持相同关系。于是所有状态压缩成 $K+1$ 个系数。处理结束后

$$G(0,t)=R(0)+\frac{t}{K}R'(0),$$

所以 Y 胜方案数为 $[x^0]R$，平局方案数为 $[x^1]R/K$。

消元后的系数不是逐状态方案数，可以为负。例如 X 只有普通棋子 1 和一枚炸弹、Y 只有棋子 2，初始 $R=x^2$；先加入 Y 的 2 后得到 $R=2x-x^2$，再加入 X 的 1 后得到 $R=2x$。最终 Y 胜数为 0，平局数为 $2/2=1$，另一种排列是 X 胜。

## 五、第二个优化：只走一条对角线，不展开二维卷积

固定本轮开始时的 a、b 和旧 R。定义

$$H_{p,q}(x)=[u^pv^q]W\,R(\phi(x)).$$

目标是当前点数出现次数对应的一个 $H_{p,q}$。不能依次把所有同值 X 棋子、再把同值 Y 棋子当成不同点数处理，那会破坏相等棋子同时淘汰的语义。

先处理数量差。若只加入 X 棋子，第 $t+1$ 次的系数转移为

$$h_i\leftarrow\frac{a+t-i}{t+1}h_i.$$

若只加入 Y 棋子，则为

$$h_i\leftarrow\frac{(b+t-i)h_i+(i+1)h_{i+1}}{t+1}.$$

因此可以先用 $|p-q|$ 步到达 $H_{p-q,0}$ 或 $H_{0,q-p}$。剩余部分保持 $p-q$ 不变，同时给双方增加一枚当前点数。

定义微分算子

$$L_{\alpha,\beta}F=x(1-x)F''+[1-\alpha+(\alpha+\beta-2)x]F'.$$

关键递推为

$$\boxed{pqH_{p,q}=(C_{p,q}-L_{\alpha,\beta})H_{p-1,q-1}-D_{p,q}H_{p-2,q-2}},$$

其中

$$\alpha=a+p-q,\quad\beta=b-p+q,$$

$$C_{p,q}=(a+p-1)(b+q-1)+(p-1)(q-1),$$

$$D_{p,q}=(a+p-2)(b+q-2).$$

负下标状态视为零；本轮中的 a、b 固定不变。沿这条对角线，$\alpha,\beta$ 也固定不变。

这个算子看似包含二阶导数，但对单项式只有两个输出项：

$$L_{\alpha,\beta}x^i=i(\alpha+\beta-1-i)x^i+i(i-\alpha)x^{i-1}.$$

因此令 cur 为 $H_{p-1,q-1}$、prev 为 $H_{p-2,q-2}$，可以直接计算

$$
\boxed{\operatorname{next}_i=
\frac{[C_{p,q}-i(a+b-1-i)]\operatorname{cur}_i
+(i+1)(\alpha-i-1)\operatorname{cur}_{i+1}
-D_{p,q}\operatorname{prev}_i}{pq}}.
$$

每步扫描 $i=0,\ldots,K$ 一遍，时间 $O(K)$，使用三个滚动系数数组即可。一个点数总共需要

$$|p-q|+\min(p,q)=\max(p,q)$$

步，而不是 $pq$ 步。这就是关于棋子数量也保持线性的关键。

## 六、对角线恒等式的来源

令 $H(u,v,x)=W R(\phi(x))$，$D_u=u\partial_u$、$D_v=v\partial_v$。链式法则给出

$$
(1-uv)\bigl(D_uD_v-uv(a+D_u)(b+D_v)\bigr)H
+uv\bigl(L_{a,b}-(D_u-D_v)\partial_x\bigr)H=0.
$$

这不是对某个特殊 R 才成立的经验式。将左边除以 W，收集 $R(\phi),R'(\phi),R''(\phi)$，三个有理函数系数分别为零。本次已使用 SymPy 对这三个符号系数作精确化简。

取 $u^pv^q$ 系数时，$D_uD_v$ 产生 $pq$；乘 $uv$、$u^2v^2$ 分别平移到上一条和上上条对角线状态。此外

$$L_{a,b}-(p-q)\partial_x=L_{a+p-q,b-p+q},$$

正好得到前述 $\alpha,\beta,C,D$。

另一个独立核对方法是直接展开生成函数：若旧多项式系数为 $r_i$，记

$$c(s,t)=[z^t](1-z)^{-s}=\frac{s(s+1)\cdots(s+t-1)}{t!},$$

其中 $c(s,0)=1$、负下标时为 0，则

$$[x^j]H_{p,q}=\sum_{i\ge j}r_i\binom ij
\sum_{t=0}^{\min(p,q-i+j)}c(a-i,p-t)c(b-j,q-i+j-t)c(i,t).$$

这个多重和只用于独立验证，不进入快速算法。它也允许 s 为负数，因而能检查中间系数为负的情形。

## 七、归一化、复杂度与实现注意事项

同点数棋子的不同排列等概率。设点数 v 在两边的出现次数分别为 $p_v,q_v$，总方案数为

$$\Omega=\frac{(n+k)!\,m!}{k!\prod_v p_v!\prod_v q_v!}.$$

输出依次是

$$P_Y=\frac{R_0}{\Omega},\qquad P_=\frac{R_1}{K\Omega},\qquad P_X=1-P_Y-P_=.$$

实际输出顺序是 $P_X,P_Y,P_=$，每个一行。所有除法使用模逆。新范围中 $n+k\le1005000,m\le1000000,K\le5001$，阶乘下标、K、单侧步数和对角线下标均严格小于模数，相关分母可逆。因为 $n\ge1$，逆元预处理上界 $\max(n+k,m)$ 一定覆盖 K。

同点数棋子先编号再均匀排列，也会得到相同概率：每个点数序列对应相同数量 $k!\prod p_v!\prod q_v!$ 的编号排列。总编号排列数 $(n+k)!m!$ 在本范围内非零模 p，故概率最简分母亦不含模数因子。

各点数的 $\max(p_v,q_v)$ 之和不超过 $n+m$，所以多项式转移为 $O((n+m)(k+1))$。点数最多 $10^5$，将 `(value<<1)|side` 编码后可用两趟 9 位基数排序，排序也为 $O(n+m)$；直接使用 `std::sort` 则还需加 $O((n+m)\log(n+m))$。阶乘、逆元和输入数组占 $O(n+m+k)$ 空间，滚动多项式额外占 $O(k)$。

复杂度采用固定 64 位字长的 RAM 模型：本题范围内的整数加乘、固定素数下的模运算计为 O(1)。求逆的快速幂仅进行常数次，固定模数下为常数代价；所有其余逆元线性预处理。若将模数也看作可增长参数，则不能照搬这一固定字长代价模型。

实现时必须保留相等的后缀最大值；每种点数开始时固定 a、b；Y 单侧原地更新从低次到高次，保证读到旧的 $h_{i+1}$；数组保留恒零哨兵 $h_{K+1}$；每个新点数开始时将 prev 清零。

递推 C、D 含约百万量级的整数乘法，在取模之前可达约 $2.01\times10^{12}$，必须先提升到 `long long`，不能用 `int` 相乘再赋值。含次数 i 的乘积也先提升到 64 位；这些值的绝对值均远小于 $2^{63}-1$。alpha 及转换后的系数可能为负，模数类构造时会规范到 $[0,p)$。两个模数余数相加小于 $2p<2^{31}-1$，模乘的原始乘积小于 $p^2<2^{63}-1$。输入编码不超过 200001，左移安全。数组动态分配，无递归。

这证明了该算法的上界。$k$ 固定时已达到读入数据的线性下界；没有据此证明把 k 当作参数时整个 $O((n+m)(k+1))$ 界也是全局最优。

## 八、未消元的独立参考程序

`reference_states.cpp` 直接保留 $\xi^i\eta^j\tau^e$，其中 $i+j\le k,e\in\{0,1\}$，不用 $\eta=1-\xi$，也不使用对角线递推。

对旧项的三个仿射替换分别做二项式展开。若保留 r 个 xi、s 个原有 eta、h 个 tau，则新单项式为 $\xi^r\eta^{i-r+s}\tau^h$，组合因子为 $\binom ir\binom js$。由公共因子和替换式直接得到转移权：

$$\sum_{t=0}^{\min(p-j+s,q-i+r-e+h)}c(a-i-e-s,p-j+s-t)c(b-j-h,q-i+r-e+h-t)c(i+j+e,t).$$

这里 c 是第六节的广义二项式系数；负次数系数为零。对所有合法 r,s,h 累加，得到新二维状态。初始仅 $(i,j,e)=(k,0,1)$ 为 1，最后在 i=0 上分别累加 e=0、e=1 的所有 j，即 Y 胜和平局方案数。此实现与标准程序的压缩表达和局部递推相对独立。

状态数 O(K^2)，r,s 枚举最多 O(K^2)，内部 t 枚举至多 min(p,q)+1。所有点数的 min(p,q)+1 之和为 O(n+m)，所以参考的时间上界为 O((n+m)K^4)，空间 O(n+m+K^2)。跳过零状态和不合法转移会加速特殊数据，因此不承诺每点均达到这个上界。

这是根据未消元生成函数重新实现的参考，**不是下载的官方源码**。只在小中规模和选定性能点运行；k=5000 时该参考的完整二维数组不符合本包 256 MiB 限制，也不用于生成该范围的标准答案。性能对照点 k=249、999 的内存均远低于 256 MiB，其失败原因是 CPU 超时。

`brute.cpp` 则直接枚举双方全部不同排列，并逐场模拟，不使用生成函数。仅用于小规模。
