# Quad Kingdoms Chess 2 题解

## 题意与算法概览

双方将棋子随机排列，普通棋子中较强者留下，同强度同时消失；X 还拥有 $k$ 枚炸弹，每枚炸弹与一个 Y 棋子同时消失。要求 X 胜、Y 胜、平局的概率。

本题的难点是炸弹会把对局切成若干段，而且同强度棋子必须整体处理。下面先建立生成函数，再将状态压缩成一个次数不超过 $K=k+1$ 的多项式。每加入一枚棋子，只需 $O(K)$ 的系数运算，最终达到 $O((n+m)(k+1))$。

## 1. 没有炸弹时，比较后缀最大值

对普通棋子序列 $S$，从右向左保留所有不小于已扫描最大值的元素，再恢复原顺序，记作 $f(S)$。相等的最大值要全部保留。

两列普通棋子的胜负，等价于 $f(A),f(B)$ 的字典序比较，空列小于非空列。

证明可以从最大强度开始：最大值较大的一方一定有棋子留下；最大值相同，则双方最大值一一抵消，数量多的一方留下。若最大值数量也相同，双方最后一个最大值同时消失，继续比较它们后面的后缀。更早出现的小棋子已经被消耗，不会影响最终胜负。

所以我们按强度从大到小加入棋子。一旦某段已经在更大强度处分出胜负，再加入小棋子不会改变它。

## 2. 只统计 Y 胜和平局

若 X 没有获胜，它的每枚炸弹都必须被消耗，并唯一对应一个被炸掉的 Y 棋子 $C$。按炸弹及对应的 $C$，将双方序列切成 $k$ 对前置普通段，以及最后一对普通段。

对炸弹前的一对普通段 $A,B$，炸弹恰好遇到 $C$ 的条件是

$$f(A)=f(B),\qquad\text{或}\qquad f(B)<f(A)<f(B+C).$$

第一种情况是普通段同时耗尽；第二种情况是 A 打完 B，但被 C 打完，随后炸弹再消耗 C。最后一个不含炸弹的普通段则必须是 Y 胜或平局。

按强度递减处理时，一对炸弹段有三种状态：

| 状态 | 含义 | 生成函数标记 |
|---|---|---|
| U | 对应的 C 尚未加入，当前普通段必须平局 | $\xi$ |
| T | C 已加入，当前普通段仍平局 | $\eta$ |
| F | C 已加入，普通段已确定 X 胜，且 C 比其剩余棋子强 | $1$ |

最后一段仍平局时标记为 $\tau$，已确定 Y 胜时标记为 $1$。因此初始状态是 $\xi^k\tau$。

## 3. 加入一种新强度的转移

设此前已处理 X 普通棋子 $A$ 枚、Y 棋子 $B$ 枚，令

$$a=A+K,\qquad b=B+1,\qquad K=k+1.$$

用 $u,v$ 分别记录本轮加入的 X、Y 棋子数。把更小的棋子插到一个已有大棋子之前，不影响后缀最大值，每个自由插入位置对应一个几何级数。

X 的 $K$ 个普通段共有 $A+K$ 个自由位置。若还有 $i$ 个 U 段，已选中的分隔棋子 C 有 $k-i$ 枚，Y 普通段的自由位置数为 $B-(k-i)+K=B+i+1$。提出公共因子

$$W=(1-u)^{-a}(1-v)^{-b},$$

并将额外的 $i$ 个位置放进 U 的局部转移。由末尾同强度棋子的数量比较，可以得到三个替换：

$$\xi\mapsto\frac{(1-u)(\xi+v\eta)}{1-uv},$$

$$\eta\mapsto\frac{(1-v)((1-u)\eta+u)}{1-uv},$$

$$\tau\mapsto\frac{(1-u)((1-v)\tau+v)}{1-uv}.$$

其中 $1/(1-uv)$ 表示双方在末尾加入同样多枚当前强度的棋子。U 可以继续等待，也可以选一枚当前强度的 Y 棋子作为 C，转为 T；不能直接变成 F，因为与当前强度相同的 C 会先被普通棋子抵消。T 中的 C 已经是更大的强度，所以允许普通段转为 X 胜。最后一段则允许转为 Y 胜。

若当前强度在两边分别出现 $p,q$ 次，本轮转移就是对替换后的生成函数乘 $W$，再提取 $[u^pv^q]$。

## 4. 两次消元，只保留一个多项式

上述替换满足

$$\xi'+\eta'-1=\frac{1-u}{1-uv}(\xi+\eta-1).$$

最终要让每枚炸弹都找到对应棋子，正好是在 $\xi=0,\eta=1$ 处求值。关系 $\xi+\eta=1$ 在每次转移下保持，因此可以从一开始就代入 $\eta=1-\xi$。

令 $\xi=x,\tau=t$。这时两者都进行同一个仿射替换

$$\phi(z)=\frac{(1-u)((1-v)z+v)}{1-uv}=\lambda z+\mu.$$

生成函数可以始终写成

$$\boxed{G(x,t)=R(x)+\frac{t-x}{K}R'(x)},\qquad\deg R\le K.$$

初始 $R=x^K$ 时，右侧恰好是 $x^{K-1}t$。若该形式在转移前成立，则

$$\phi(t)-\phi(x)=\lambda(t-x),\qquad
\frac{d}{dx}R(\phi(x))=\lambda R'(\phi(x)),$$

所以替换、乘公共因子以及提取 $u,v$ 系数后，形式仍成立。

最终代入 $x=0$，得到

$$G(0,t)=R(0)+\frac{t}{K}R'(0).$$

因此 Y 胜方案数为 $R_0$，平局方案数为 $R_1/K$。现在只须维护 $K+1$ 个系数。消元后的中间系数可以为负，它们不再分别表示某一种局面数量。

## 5. 如何在线性步数内处理同强度的 $p,q$ 枚棋子

本轮固定开始时的 $a,b$ 和旧多项式 $R$。定义

$$H_{p,q}(x)=[u^pv^q](1-u)^{-a}(1-v)^{-b}R(\phi(x)).$$

我们只需要一个指定的 $H_{p,q}$，不能真的建立 $p\times q$ 的状态表。先走 $|p-q|$ 步到一条坐标轴，再沿对角线同时增加两边数量。

若只加入 X 的棋子，第 $t+1$ 步为

$$h_i\leftarrow\frac{a+t-i}{t+1}h_i.$$

若只加入 Y 的棋子，则

$$h_i\leftarrow\frac{(b+t-i)h_i+(i+1)h_{i+1}}{t+1}.$$

剩下的对角线递推用到

$$\alpha=a+p-q,\qquad\beta=b-p+q,$$

$$C_{p,q}=(a+p-1)(b+q-1)+(p-1)(q-1),$$

$$D_{p,q}=(a+p-2)(b+q-2).$$

若 `cur` 为 $H_{p-1,q-1}$、`prev` 为 $H_{p-2,q-2}$，则

$$\boxed{\operatorname{next}_i=
\frac{[C_{p,q}-i(a+b-1-i)]\operatorname{cur}_i
+(i+1)(\alpha-i-1)\operatorname{cur}_{i+1}
-D_{p,q}\operatorname{prev}_i}{pq}.}$$

负下标状态视为零。每步只扫描 $i=0,\ldots,K$，需要三个滚动数组。

### 对角线递推的依据

令微分算子

$$L_{\alpha,\beta}F=x(1-x)F''+[1-\alpha+(\alpha+\beta-2)x]F'.$$

对任意单项式，

$$L_{\alpha,\beta}x^i=i(\alpha+\beta-1-i)x^i+i(i-\alpha)x^{i-1}.$$

对 $H(u,v,x)=WR(\phi(x))$ 使用链式法则，可以得到

$$(1-uv)\bigl(D_uD_v-uv(a+D_u)(b+D_v)\bigr)H
+uv\bigl(L_{a,b}-(D_u-D_v)\partial_x\bigr)H=0,$$

其中 $D_u=u\partial_u,D_v=v\partial_v$。验证时将左侧收集成 $R(\phi),R'(\phi),R''(\phi)$ 三项，其系数分别为零。

提取 $u^pv^q$，并使用 $L_{a,b}-(p-q)\partial_x=L_{\alpha,\beta}$，得到

$$pqH_{p,q}=(C_{p,q}-L_{\alpha,\beta})H_{p-1,q-1}-D_{p,q}H_{p-2,q-2}.$$

再代入单项式公式，就是上面的逐系数递推。这说明我们计算的是同强度棋子的整体转移，而非把相等棋子错误地当作不同强度依次插入。

## 6. 从方案数变成概率

设强度 $v$ 在两边的出现次数为 $p_v,q_v$。不同强度序列的总对数为

$$\Omega=\frac{(n+k)!\,m!}{k!\prod_vp_v!\prod_vq_v!}.$$

题面虽然将棋子视作带编号，但每个强度序列对应的编号排列数都相同，因此这些强度序列仍然等概率。故

$$P_Y=R_0/\Omega,\qquad P_=R_1/(K\Omega),\qquad P_X=1-P_Y-P_=.$$

按 $P_X,P_Y,P_=$ 的顺序输出。所有除法都是模 $998244353$ 的逆元。

## 复杂度与实现细节

一种强度需要 $|p-q|+\min(p,q)=\max(p,q)$ 步，而所有强度的这个量之和不超过 $n+m$。因此多项式部分为 $O((n+m)(k+1))$。

参考实现将“强度、所属方”编码为一个不超过 $200001$ 的整数，用两趟基数排序线性分组。加上阶乘和逆元预处理，总复杂度为

$$\boxed{O((n+m)(k+1))\text{ 时间},\quad O(n+m+k)\text{ 空间}.}$$

若改用比较排序，需要额外计入 $O((n+m)\log(n+m))$。

实现时，同一种强度内的 $a,b$ 必须固定；每种强度开始时清零 `prev`。Y 单侧原地更新应从低次到高次，保证读到旧的 $h_{i+1}$；数组保留恒零的第 $K+1$ 项。$k=0$ 时仍有 $K=1$，算法无需特判。所有阶乘下标和除数均小于模数；计算 $C,D$ 及带次数的乘积时须先提升到 64 位。
