# 云阶之差：题解与扩大范围审计（k ≤ 10^14）

本版保留此前讨论的“整数分段线性近似定位 + 确定性选择”现场计算算法。新增的是 128 位安全运算，以及在物化候选前执行常数轮流式 BFPRT 筛减。没有答案表，没有把标准程序替换成二分答案。下面证明的是确定性最坏复杂度上界，不声称理论最优或目前全局最优。

## 1. 整数化与有限等差数列

设较低观测台编号为 i，另一座为 i+d。因为 a>0、b≥0、i≥1，高度随编号严格递增。将高差乘以 a：

$$X_{d,i}=a(h_{i+d}-h_i)=d(ad+2b)+2ad\,i.$$

记 B_d=d(ad+2b)、s_d=2ad、N_d=n-d。固定 d 时，候选是

$$B_d+s_d,\ B_d+2s_d,\ldots,\ B_d+N_ds_d.$$

每个元素对应一个无序数对，重复数值按重数保留。找到全部整数候选的第 k 小值 X 后，令 g=gcd(X,a)，输出 X/g 与 a/g。

## 2. 仅需 D=O(√k) 行

令 D 为满足 D(D+1)/2≥k 的最小正整数。输入保证 k≤n(n−1)/2，所以 D≤n−1。

前 D+1 座观测台产生至少 k 个数对，其中最大高差乘 a 后为

$$W=D\bigl(a(D+2)+2b\bigr).$$

所以答案≤W。对于 d>D，第 d 行的首元素 d(a(d+2)+2b)>W，因为 a>0、b≥0。因此所有不超过 W 的候选都在前 D 行。D 用整数二分求得，不用浮点开根。

在本题范围内，D≤14,142,136。D+1≤n 是这里不可省略的前提。

## 3. 真实计数的整数近似

对实数 x∈[0,W]，定义截断 [z]_0^u=min(u,max(0,z))，并令

$$C_d(x)=\left[\frac{x-B_d}{s_d}\right]_0^{N_d},\qquad
F_d(x)=\lfloor C_d(x)\rfloor,\qquad F(x)=\sum_{d=1}^D F_d(x).$$

F(x) 就是不超过 x 的候选个数。定义整数权重和连续分段线性函数：

$$w_d=\left\lfloor\frac W{s_d}\right\rfloor,\qquad
G(x)=\sum_{d=1}^D w_d[x-B_d]_0^{s_dN_d}.$$

设 q_d=[x-B_d]_0^{s_dN_d}。因 B_d≥0、x≤W，有 0≤q_d≤W。因此

$$0\le C_d(x)-\frac{w_dq_d}{W}
=\left(\frac W{s_d}-\left\lfloor\frac W{s_d}\right\rfloor\right)\frac{q_d}{W}<1.$$

又有 0≤C_d−F_d<1，所以每行 F_d 与 w_dq_d/W 的差在 (−1,1) 内。求和得到

$$\boxed{\left|F(x)-G(x)/W\right|<D.}$$

这里采用绝对误差界，不把两个同号误差错误地相加成固定方向。饱和行和首元素之前的区间也满足该式。

## 4. 把所有候选缩到一个小区间

取实数根 y_L 满足 G(y_L)=(k−D)W。由于 D≤k、G(0)=0，且 G(W)/W>F(W)−D≥k−D，该根存在；k=D 时直接取 y_L=0。

若 G(y_R)=(k+D)W 在 [0,W] 内有解，则也取这个根。令 L=⌊y_L⌋，R=⌊y_R⌋；若右侧根不存在，改取 R=W。

所有实际候选都是整数，故 F(⌊y⌋)=F(y)，即根向下取整不会改变对应的真实计数。根据上面的误差界，

$$k-2D<F(L)<k\le F(R)<k+2D.$$

右根不存在时，F(W)≥k，而且 G(W)/W<k+D，同样给出 F(W)<k+2D。因此答案一定在 (L,R]，区间中按重数计算的候选数量

$$\boxed{m=F(R)-F(L)<4D.}$$

注意是左开右闭区间。直接把 y 的近似浮点值取整，或者把 L 端点包含进来，都可能造成排名偏移。

## 5. 在线性时间扫描根

每一项只有两个斜率变化点：

$$B_d=d(ad+2b),\qquad E_d=B_d+s_dN_d=d\bigl(a(2n-d)+2b\bigr).$$

B_d 随 d 严格递增。又有

$$E_{d+1}-E_d=a(2n-2d-1)+2b>0\quad(1\le d\le n-2),$$

所以 E_d 也严格递增。两个指针归并这两列断点即可，不需要排序或保存断点数组。同一坐标出现开始、结束事件时都要处理。到达 B_d，斜率加 w_d；到达 E_d，斜率减 w_d。

在当前线段起点 x，已知精确 G(x)=value 和非负斜率 slope。根的下取整直接是

$$x+\left\lfloor\frac{target-value}{slope}\right\rfloor.$$

slope=0 时不能做除法。更重要的是，本版不先无条件计算 slope·dx：对于正 gap=target−value，使用

$$\lceil gap/slope\rceil\le dx\iff(gap-1)/slope<dx$$

判断该段是否到达目标。若到达右目标就立即停止；若未到达，则 value+slope·dx<target_R。这使乘法更新有一个明确的 128 位上界，而不是假设完整的 G(W) 一定不会溢出。全程没有浮点运算。

## 6. 为什么原来的直接候选数组不再适合 256 MB

扩大后，W、候选值和最简分子都可能超过 64 位。仅把 vector<long long> 换成 vector<__int128> 并 reserve(4D)，上界便接近 864 MiB，不能沿用 256 MB 配置。

本版在原区间上增加流式的确定性筛减，最后仍使用 BFPRT。维护当前 (L,R] 和精确的 F(L)、F(R)，全局目标始终为 k。令物化阈值 T=max(D,256)。若 m≤T，才将当前候选全部放入数组。

否则，按逐行生成的顺序，每五个候选作为一组，在栈上的长度 5 数组内排序，仅保存该组中位数。最后不足五个的组也取中位数。通过原地 BFPRT 求这些中位数的中位数 p。

**中位数数组释放后，再执行后续步骤；不会让它和最终候选数组同时存在。**

扫描所有行求 le=F(p) 和 eq=恰好等于 p 的候选个数。每行严格递增，所以每行至多贡献一个相等元素。然后：

- 若 k≤le−eq，令 R=p−1，F(R)=le−eq。
- 若 le−eq<k≤le，p 就是答案。
- 否则令 L=p，F(L)=le。

这些判断使用全局计数，不会在逐轮筛减中重复或漏减排名。每轮只需要保存一个上下界，不存每行状态；下一轮重新按上下界生成还未排除的候选即可。

## 7. 流式筛减轮数与内存上界

五个一组的中位数之中位数，能保证两侧各至少有 3m/10−6 个元素（计入重数的非严格不等式）。若没有直接返回等值区间，只保留严格一侧，因此下一轮

$$m'\le 7m/10+6.$$

从 m_0<4D 开始，五轮后

$$m_5<4D(0.7)^5+6\sum_{j=0}^4(0.7)^j
<0.67228D+16.64\le\max(D,256).$$

最后一个不等式在 D≥256 与 D<256 两种情况下均成立。因此最多五轮；并不是对数轮全区间扫描。一般意义的 median-of-medians 的分组保证允许至多一组不足五个，所以常数 6 给了边界余量。

一次只持有下列数组之一：

- ceil(m/5) 个 128 位中位数，最多 ceil(4D/5) 个；
- m≤max(D,256) 个 128 位最终候选。

每个元素 16 字节，最大 D 时数组本体不超过

$$16D=226,274,176\ \text{字节}<216\ \text{MiB}.$$

在本包测量的 GNU libstdc++/glibc 环境下 reserve 按所需容量分配，释放大向量后再分配下一向量。仅有少量栈和 I/O 开销，配置维持 256 MB。包内有实际峰值 RSS 记录及独立的 256 MiB 地址空间限制运行；sanitizer 运行不施加该限制，因为 ASan 需要很大的虚拟地址空间。

## 8. 总复杂度与计算模型

定位 D 为 O(log k)，归并至多 2D 个断点为 O(D)。初始计数 O(D)。流式筛减至多五轮，每轮扫描行和候选 O(D+m)=O(D)，选择中位数也是最坏 O(D)。最终物化和 BFPRT 为 O(D)。总计确定性最坏 O(√k) 时间、O(√k) 额外空间；BFPRT 的递归栈深为 O(log D)，其余大过程均为迭代。

这是本题有限数值范围下的**字长 RAM 模型**：64 位/128 位整数的四则运算和比较按常数次字长操作计。GCC 的 __int128 是编译器扩展，标准程序按 GNU C++17 编译。没有宣称对任意精度整数也有同样的位复杂度；若参数任意增长，应另计大整数运算成本。若单独让 a 无界，欧几里得约分还需 O(log a) 次字长运算，本题 a≤10^6，该额外项有固定小上界。

独立参考程序使用二分答案及直接精确计数，最坏 O(√k log W) 时间、O(1) 附加空间。它仅用于验证，不是本包标准程序。所有正式点还有独立的 Boost cpp_int 排名证书，检查 F(X−1)<k≤F(X)，因此即使某些大点没有完整运行参考的答案二分，也可以独立证明给定答案确实是第 k 小。

## 9. 位宽审计

本版不是只修改 MAX_K。以下均在运算前提升类型，而不是发生溢出后再转换：

| 量 | 本范围下安全界 / 处理方式 |
|---|---|
| n、k、a、b | 输入本身在有符号 64 位内 |
| n(n−1)/2、求 D 时的三角数 | 乘法使用 128 位，最大量级 10^24 |
| D、候选索引 | D≤14,142,136，初始候选<56,568,544，32 位下标足够 |
| s_d=2ad | ≤28,284,272,000,000，64 位足够 |
| B_d、W、候选 X | W<2.29×10^20，必须用 128 位 |
| E_d | <2.83×10^25，使用 128 位 |
| w_d | 最坏可能超过 2^63−1，使用 128 位 |
| slope | 用粗界 D·W/2<1.62×10^27 即已足够，使用 128 位 |
| (k±D)W | <2.30×10^34，严格小于 2^127−1≈1.70×10^38 |
| value+slope·dx | 先检测是否跨过右目标；仅在结果<target_R 时做乘法 |
| F(L)、F(R)、区间内部计数 | 始终<k+2D<1.01×10^14，64 位累加安全 |
| 行下标乘 step | 即使上界较大，也先使用 128 位相乘 |
| gcd 与输出 | 求 gcd(X mod a,a)，余数转 64 位安全；分子用 128 位十进制转换 |

没有取模逆元或模意义除法。所有出现的除法都是精确整数商或明确的向下取整，且分母正。行计数先处理负差并饱和到 N_d，再转回 64 位。原题完整绝对高度可能很大，但标程不直接平方绝对高度；小暴力使用 128 位平方 (ai+b)，且限制 n≤500。

## 10. 输出与检查器

本版样例 5 的分子为 228242058701571982240，已经超过 long long。因此旧版内置 ncmp（读 signed 64-bit integer）不能继续使用。

采用 UOJ 原生 use_builtin_checker wcmp，比较两个规范十进制 token，忽略 token 间的空白。题面明确不使用前导加号、无意义前导零、斜杠或科学记数法。最简分数唯一，故无需自定义 SPJ。管理员的 arbitrary-precision certificate 是本地验证工具，**不是上传使用的 checker**。
