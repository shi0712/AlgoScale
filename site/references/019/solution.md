# 双线括号：出题者题解

本题采用本对话确认的现场计算算法：整数流证明参数代价凸性，线性计算固定参数代价，再二分最小值。时间 O(n log n)，额外空间 O(n)。没有使用答案表。

本文的 O(n log n) 是已证明的上界，优于原公开题解逐参数枚举的 O(n²)，不宣称理论最优或目前全局最优。原问题来源为 QOJ 3743 B；下面的凸性证明是本出题包采用的优化依据。

### 参数化：固定蓝色左括号数

用 0、1 表示两种非公共色，2 表示蓝色。颜色总数为 A0,A1,B，原左括号数为 O0,O1,O2。两条需平衡的序列长度必须为偶数，令 h0=(A0+B)/2、h1=(A1+B)/2。

若最终蓝色左括号数为 b，各色左括号目标数固定为 `(h0−b,h1−b,b)`。记最少翻转数为 F(b)。公开算法逐个枚举 b；本方案先证明 F 离散凸，再二分其最小值。

### 可行 b 是一个可直接计算的整数区间

固定每色左括号总数后，把该色的所有左括号放在该色的最前面，会同时最大化每个前缀的左括号数。因此这种完全靠前的排列可行，当且仅当任何排列可行。

在一个全局前缀里，颜色 j、2 的个数为 p_j,p_2，该二色序列需要至少 z=ceil((p_j+p_2)/2) 个左括号。最大可能数为

\[
\min(h_j-b,p_j)+\min(b,p_2).
\]

其不小于 z 等价于四个线性条件，其中 `h_j≥z` 和 `p_j+p_2≥z` 自动成立，另外两个是

\[
z-p_j\le b\le h_j+p_2-z.
\]

对所有前缀和 j=0,1 求交，并与 `0≤b≤B`、`0≤h_j−b≤A_j` 求交，O(n) 得到 `[lo,hi]`。空区间输出 −1。后续二分始终在真实可行区间内，避免把无穷大代价错误当成平坦函数。

### 离散凸性的整数流证明

设每个字符变量 x_i∈{0,1} 表示最终是否为左括号，翻转代价为常数 `Σ原左括号` 加 `Σ(1−2·原左括号指示)x_i`。

为第一条二色序列建立节点 U1…U_L0，相邻节点有 U_r→U_(r+1) 的非负流边；每个奇数 r 节点消耗一个单位。为第二条建立 V1…V_L1，链方向相反，即 V_(r+1)→V_r；每个奇数 r 节点供给一个单位。

每个字符成为一条容量为 1、费用为其线性翻转系数的边：

- 蓝色字符在两序列中的位置为 p,q：边 V_q→U_p；
- 颜色 0 字符位置 p：边 L→U_p；
- 颜色 1 字符位置 q：边 V_q→R。

链上的非负流恰好表达所有前缀 `Σx≥ceil(前缀长度/2)`；链末没有继续输出，表达总左括号数恰为 h_j。

再加边 R→L，流量记 t；令 L 的供给为 h0−B，R 的需求为 h1−B（允许负值，即反向供需）。从总流量守恒立即得 `t=B−b`。所以固定 b 相当于只固定网络中一条边的流量，其余需求和容量都与 b 无关。

允许实数流时，最小费用值关于 t 是凸函数：任意两个可行流的凸组合在中间 t 可行，且费用线性。更关键的是，固定整数 t 后该问题仍是整数容量、整数需求的网络流，存在整数最优解。因此整数点上的连续最优值恰好等于 F(b)，不是整数松弛的下界。

于是 `F(b−1)+F(b+1)≥2F(b)`。如果 `F(mid)≤F(mid+1)`，最左最小值在左半区间，否则在右半区间。无需数值近似，也没有随机假设。

### 每次 F(b) 用 O(n) 精确计算

先按各色目标数做最少必要翻转：增加左括号时改该色最早的右括号；减少时改该色最晚的左括号。交换论证表明，在同样翻转次数下它们使所有前缀尽量大。基础费用是各色 `|目标−原数|` 之和。

之后保持每色总数不变，一次额外交换是把该色最早剩余右括号改左、最晚剩余左括号改右，费用 2。记每色交换次数为 k0,k1,k2。最多有效交换 cap_j 次，其中 cap_j 是当前该色前“目标左括号数”个位置中的右括号数；达到 cap_j 后该色已经完全左括号靠前，更多交换不可能改善可行性。

在某前缀，令 X_j=min(该色前缀右括号数,该色后缀左括号数)。做 k_j≤cap_j 次交换，使此前缀平衡增加 `2 min(k_j,X_j)`。对二色序列若当前亏空需要 z 次这样的补偿，则

`min(k_j,X_j)+min(k_2,X_2)≥z`。

将其展开，汇总为常数个约束：`k_j≥lower_j`、`k_2≥lower_2`、`k_j+k_2≥pair_j`，以及 caps。常数项的可行性已由 b 的可行区间保证。

对给定 k2，最少 k0/k1 分别是 `max(lower_j,pair_j−k2)`。这个三段折线的一个最小点为

`k2=min(cap2,max(lower2,pair0−lower0,pair1−lower1))`。

代回求 k0、k1，基础费用加 `2(k0+k1+k2)` 即 F(b)。可行 b 保证这些值满足各色上界。总时间 O(n log n)，空间 O(n)。


### 扩大到 n≤500000 后的实现审计

所有字符和颜色数组均按输入 n 动态分配；没有保留原 n≤6000 的固定数组。计数、前缀平衡、参数区间和费用均为 O(n) 大小；lo+hi≤1000000，中间费用界也远小于 32 位有符号上限。标准程序不递归，不存在与 n 成正比的调用栈。

复杂度采用至少 32 位整数索引、常数时间加减比较的 word-RAM 模型。每次 cost 扫描常数遍长度 n 的数组；二分区间至多 n+1 个整数，共 O(log n) 次，每次同时计算两个相邻值。输入和输出费用分别为 O(n) 和 O(1)，已包括在整体界内。

### 本次独立验证

`brute.cpp` 是双前缀余额 DP，不使用蓝色参数凸性或原贪心。已覆盖全部 n=1..5 的 9330 个括号/颜色输入，以及 440 个更大随机输入（最大 n=250）。正式点中 7 个较小输入另由该 DP 核对；所有正式点做了颜色 0/1 互换、逆序并交换左右括号两种等价变换，共 40 次。全部 20 个正式点另运行 ASan/UBSan，无报错。具体记录见 ../records/。

标准与慢程序使用相同的 -std=c++17 -O2 -pipe。`slow.cpp` 保留同一固定参数求值，但枚举每个可行参数，是公开 O(n²) 方法的直接对照，未添加休眠或人为冗余。
