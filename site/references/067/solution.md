# 题解：层叠果园

记 (m=k-1)。当 (k=1) 时答案显然是 (n)，以下假设 (mge1)。

## 1. 目标函数

对节点 (v)，令

[
c_v[d]=|{u:operatorname{dist}(u,v)=d}|.
]

以 (v) 为中心的方案数为

[
sum_{dge1}inom{c_v[d]}m.
]

因此只需在一次遍历中维护每个中心的距离分布及其组合数总和。

## 2. 子树距离数组的总长度

令 (a_v[d]) 表示 (v) 的子树内、距离 (v) 恰好为 (d) 的节点数。显然 (a_v[0]=1)，并且可以由孩子数组平移相加得到。

若 (v=x_0,x_1,ldots,x_h) 是从 (v) 向下的一条最长路径，则这些节点的子节点数严格递减，且最后一个为 (0)。所以

[
hledeg(v),qquad |a_v|=h+1ledeg(v)+1.
]

于是

[
sum_v|a_v|lesum_v(deg(v)+1)=2n-1.
]

这说明所有 (a_v) 可以在线性总空间和线性总时间内计算与保存。

## 3. 换根公式

设 (u) 是 (v) 的父节点。把中心从 (u) 移到 (v)，先假设所有节点到中心的距离都增加一，得到 (c_u[d-1])。但 (v) 子树内的节点需要修正：距离为 (d-2) 的节点被多算，距离为 (d) 的节点需要补回。因此

[
c_v[d]=c_u[d-1]+a_v[d]-a_v[d-2],
]

不存在的下标视为 (0)。

维护

[
F(c)=sum_{dge0}inom{c[d]}m.
]

把数组的起点用一个可移动的下标表示，整体把所有距离加一只需将起点减一，不需要搬移数组，也不改变 (F)（新加入的 (c[0]=0) 对 (mge1) 没有贡献）。随后只需处理

[
Delta[d]=a_v[d]-a_v[d-2].
]

这个修正只在 (0le dle |a_v|+1) 内可能非零。每次把一个计数 (x) 改为 (x+Delta) 时，用预处理的阶乘和逆阶乘在 (O(1)) 时间更新

[
Fleftarrow F-inom{x}{m}+inom{x+Delta}{m}.
]

深度优先遍历返回时按相反方向撤销这些修改即可。

## 4. 正确性说明

换根公式直接按节点是否在 (v) 子树内分类得到：子树外节点的距离增加一；子树内节点在整体平移后恰好需要减去 (a_v[d-2]) 并加上 (a_v[d])。因此维护数组在每个 DFS 时刻都等于当前中心的真实距离分布。

对于 (mge1)，(inom{c_v[d]}m) 正好是从距离为 (d) 的节点中选择 (m) 个的方式数。由于集合非空，这些节点的共同距离唯一，且中心不在 (dge1) 的球层中，所以各项互不重复。维护的 (F) 还包括 (d=0)；只有 (m=1) 时该项为 (1)，对每个中心减去一次即可。

## 5. 复杂度

组合数预处理为 (O(n))。所有子树数组长度之和为 (O(n))，每条换根边的修正次数为 (O(|a_v|+1))，总次数仍为 (O(n))。

因此单个测试用例的时间复杂度为 (O(n))，空间复杂度为 (O(n))。所有测试用例的总 (n) 不超过 (10^6)，所以总复杂度也为 (O(sum n))。

实现使用 C++17，模数为质数且 (n<998244353)，阶乘逆元可通过费马小定理预处理。
