# Magic Tiles 题解

## 1. 不计算巨大得分，只比较段长

记长为 $x$ 的连续段权值为 $W(x)=100^{100^x}$。整个网格只有 $10^{18}$ 行，每行至多选一个格子，所以任何方案最多有 $10^{18}$ 个非空段。

对任意 $x\ge1$，

$$\frac{W(x+1)}{W(x)}=100^{99\cdot100^x}>10^{18}.$$

因此一个更长段的优势，超过所有更短段的可能贡献。比较两个方案时，找到最大的、出现次数不同的长度；这一长度出现次数更多的一方更优。

目标等价于最大化“全部正段长按非增序排列”的字典序。后续只维护长度多重集合，完全不计算 $W$。

## 2. 删除被包含的黑色区间

把两列的黑段放到同一数轴，按左端点升序、同左端点时右端点降序排序。若区间 $I$ 被另一个区间 $J$ 包含，可以删除 $I$。

证明用交换：$I,J$ 必在不同列，因为同列黑段互不相交。把 $I$ 范围内选中的格子全部改到 $J$ 所在列，并补满这一范围。由于 $I$ 是原列的完整黑段，其选中段不会越过两端接到其他黑段；另一列原有的段只会被延长或合并，不会被切断。

于是若干受影响的段被合并成至少同样长的一段，段长多重集合的字典序不会变差，$I$ 不再被使用。重复交换即可得到不使用任何被包含区间的最优方案。

扫描时只保留右端点超过当前最大右端点的区间。保留后，左、右端点都严格递增。

## 3. 相交关系变成若干条链

一行最多属于两个输入黑段，因为只有两列。保留区间中，如果第 $i$ 个区间与第 $i+2$ 个相交，第 $i+1$ 个也会覆盖该交点，从而出现三重覆盖，矛盾。

所以每个区间只可能与前驱、后继相交。设保留区间共有 $q$ 个，第 $i$ 个长度为 $L_i$；与前驱的交长为 $d_i$，规定 $d_1=d_{q+1}=0$。不相交处取交长零，可以统一作为一条链处理。

相邻区间的交集可以完整分配给一侧。若把它拆给两边，将分界点移向某个端点，可以让受影响的较长段继续变长，而另一侧保留交集外的部分。交集内部若还有额外碎段，也可一并合入该较长段。因此总能找到不分割交集的最优方案。

于是一个区间只需考虑是否失去左、右交集，贡献为以下四种之一：

$$L_i-d_i,\quad L_i-d_i-d_{i+1},\quad L_i,\quad L_i-d_{i+1}.$$

交集分别位于区间的前缀、后缀，且不存在三重覆盖，因此剩余部分仍是连续段。长度零时不产生段。

## 4. 两状态链 DP

处理到区间 $i$ 前，区间 $1,\ldots,i-1$ 的贡献已经确定，而区间 $i$ 尚未加入答案。定义：

- $\operatorname{dp}_0$：左交集由 $i-1$ 获得，区间 $i$ 损失 $d_i$。
- $\operatorname{dp}_1$：左交集由 $i$ 获得，区间 $i$ 不损失 $d_i$。

状态值是当前最优段长多重集合。用 $A+\{x\}$ 表示加入一个正长度 $x$，$x=0$ 时不变。

若右交集给当前区间 $i$，下一状态是 $0$；若给 $i+1$，下一状态是 $1$。所以

$$\begin{aligned}
\operatorname{ndp}_0&=\max\left(\operatorname{dp}_0+\{L_i-d_i\},\ \operatorname{dp}_1+\{L_i\}\right),\\
\operatorname{ndp}_1&=\max\left(\operatorname{dp}_0+\{L_i-d_i-d_{i+1}\},\ \operatorname{dp}_1+\{L_i-d_{i+1}\}\right).
\end{aligned}$$

初始两状态均为空，结束后取较大者。每个交集独立分配给一侧，DP 恰好覆盖全部分配；同一状态的未来可选贡献相同，而向两份多重集合加入相同内容不改变字典序，因此只保留当前较优者合法。

## 5. 持久化线段树维护长度频率

直接保存排序后的长度数组，会使插入和比较变成线性时间。先将每个区间的四种正贡献离散化，候选数至多 $4q$。

在线段树叶子保存各长度的出现次数，长度越大坐标越靠右。一次插入只修改一条根到叶路径，使用持久化保存不同 DP 状态。

比较两个状态时，从右子树开始，找到最大的频率不同坐标，比较该处次数即可。为了能立即跳过完全相同的子树，还需要精确判等。

### 用结构唯一编号判等

叶子直接以频率编码。内部节点完全由左右孩子编号 $(l,r)$ 决定：若这对孩子已存在，复用旧编号；否则建立新节点。这称为结构唯一化。

参考实现用开放寻址散列表查找孩子对，但发生哈希冲突时仍比较完整的孩子对。因此同层的节点编号相等，当且仅当整段频率向量相同；不会出现“哈希碰巧相同就误判答案”的问题。

### 虚拟比较后只建立胜者

一轮有四个候选，但只保留两个状态。先比较 $A+\{x\}$ 与 $B+\{y\}$，不真正插入。

递归比较时，只需在叶子处为对应位置临时加一。相同编号且临时增量相同的子树可直接跳过；额外变化只位于两条路径上，第一次真实差异找到后就结束。因此候选比较访问 $O(\log q)$ 层量级的节点。选出胜者后，才真正做一次持久化插入。

每个区间只建立两条更新路径，节点数为 $O(q\log q)$。最终按右子树优先遍历，按频率展开长度，就得到所需的非增序输出。

## 6. 正确性与复杂度

巨大得分等价于段长字典序；包含区间可通过交换删除；剩余相交图为链，交集可完整归于一侧；两状态 DP 穷尽所有这样的分配，并保持每种边界状态的最优答案；持久化树只改变表示和比较方式。因此输出长度来自一个得分最大的合法选择。

设原输入区间总数为 $K=n+m$。排序与离散化为 $O(K\log K)$，DP 有 $O(K)$ 轮，每轮常数次 $O(\log K)$ 比较与更新。在散列表探测平均为常数的通常假设下，参考实现为

$$\boxed{\text{平均 }O(K\log(K+1))\text{ 时间},\quad O(K\log(K+1))\text{ 空间}.}$$

散列性能假设只影响运行时间，结果判等仍然精确。若使用比较树实现结构唯一化，可获得确定的比较次数上界，但会多一个对数因子。

端点达到 $10^{18}$，长度和交长均使用 64 位整数。输入同列区间之间至少隔一行白格，这保证不同原黑段的选中部分不会在输出时意外合并。不要把零长度加入频率树，输出只包含正长度和它们的总个数。
