# Discrete Fourier Transform 题解

## 1. 将被修改元素移到零号位置

令

$$g_0=0,\qquad g_j=f_{(k+j)\bmod n}\quad(1\le j<n),$$

并计算它的 DFT：

$$A_t=\sum_{j=0}^{n-1}g_je^{-2\pi\mathrm ijt/n}.$$

若将原来的 $f_k$ 替换为整数 $x$，则

$$F_t(x)=e^{-2\pi\mathrm ikt/n}(A_t+x).$$

前面的因子模长为一，所以 $|F_t(x)|=|A_t+x|$。这里 $x$ 是新数值，允许为任意整数，并不受输入范围 $[-2000,2000]$ 限制。

写 $A_t=a_t+b_t\mathrm i$，目标平方为

$$\boxed{H(x)=\max_t((x+a_t)^2+b_t^2)
=x^2+\max_t(2a_tx+a_t^2+b_t^2).}$$

因此问题变为：求一组直线的上包络，再在包络加 $x^2$ 后求整数最小值。

## 2. 任意长度 DFT：Bluestein 算法

$n$ 不一定是二次幂。直接给原序列补零后做 FFT，会改变单位根，得不到原长度的 DFT。

利用 $2jt=j^2+t^2-(j-t)^2$，有

$$e^{-2\pi\mathrm ijt/n}=e^{-\pi\mathrm ij^2/n}e^{-\pi\mathrm it^2/n}e^{\pi\mathrm i(t-j)^2/n}.$$

令

$$P_j=g_je^{-\pi\mathrm ij^2/n},\qquad Q_d=e^{\pi\mathrm id^2/n},$$

则

$$A_t=e^{-\pi\mathrm it^2/n}\sum_jP_jQ_{t-j}.$$

右侧是一段卷积。取最小的二次幂 $L\ge2n-1$，将正下标 $Q_j$ 放在 $j$，负下标 $Q_{-j}=Q_j$ 放在 $L-j$，其余补零。所需差值位于 $[-n+1,n-1]$，这些下标不会混淆，循环卷积的前 $n$ 项恰好是目标值。

用两次正 FFT、一次逆 FFT 求卷积即可。若 $n$ 本身是二次幂，直接 FFT。

输入为实数，所以 $A_{n-t}=\overline{A_t}$；加上实数 $x$ 后，两者模长相同，只需保留 $0\le t\le\lfloor n/2\rfloor$。偶数长度的 $t=n/2$ 也要保留。

## 3. 维护直线上包络

每个频率对应

$$\ell_t(x)=m_tx+c_t,\qquad m_t=2a_t,\quad c_t=a_t^2+b_t^2.$$

按斜率递增排序，相同斜率只保留最大截距。用栈保存包络上的直线及其生效起点。

若栈顶为 $(m_1,c_1)$，新线为 $(m_2,c_2)$，$m_2>m_1$，则新线从交点

$$z=\frac{c_1-c_2}{m_2-m_1}$$

开始超过旧线。若 $z$ 不大于栈顶的生效起点，栈顶没有有效区间，弹出后继续比较；否则以 $z$ 为新线起点入栈。第一条线的起点为负无穷。

每条线至多入栈、出栈一次，所以排序后线性完成。

## 4. 先求实数最优点，再检查相邻整数

设包络某段为 $m_jx+c_j$，生效区间为 $[L_j,L_{j+1}]$，则

$$H(x)=x^2+m_jx+c_j$$

在这段的顶点是 $v_j=-m_j/2$。若 $v_j>L_{j+1}$，该段到结束仍在下降；否则第一个这样的区间内，最优点是

$$x^*=\max(L_j,v_j).$$

其依据是凸性：直线最大值是凸函数，加上 $x^2$ 后严格凸，各段导数向上增长，跨越交点时也只会向上跳。因此从左到右第一次不再下降的位置就是唯一实数最优点。

在最优点左侧，凸函数不增；右侧不减。故整数最优点一定是

$$\lfloor x^*\rfloor\quad\text{或}\quad\lceil x^*\rceil.$$

两个都要比较，不能只四舍五入，因为最优点两侧的增长速度可能不同。参考实现为缓解整数边界处的舍入影响，再多检查左右各一个整数，即 $\lfloor x^*\rfloor-1$ 到 $\lfloor x^*\rfloor+2$。

最终直接计算 $\max_t((x+a_t)^2+b_t^2)$ 并开平方，减少展开式中大数相减的误差。

## 5. 精度与边界处理

使用 `long double` 完成复数 FFT、交点和距离计算。参考实现每隔一段重新计算单位根，减少递推旋转的累计误差；直流项 $A_0$ 以及偶数长度的 $A_{n/2}$ 用整数加减重新求出。

Bluestein 的相位先将 $j^2$ 对 $2n$ 取模，再计算三角函数；$j^2$ 必须先用 64 位计算。排序比较器使用正常数值大小关系，不用可能破坏严格弱序的 epsilon 比较。

虽然替换值没有给定范围，但令 $S=\sum_{i\ne k}|f_i|$，则 $|a_t|\le S$。在 $x>S$ 时所有频率模长平方都递增，在 $x<-S$ 时都随 $x$ 增加而递减，因此最优点一定在 $[-S,S]$。这也保证整数候选远在 64 位范围内。

$n=1$，或除被修改位置外全部为零时，可以把该位置改成零，答案为零。输出的是最小模长，而非替换值或模长平方。

## 正确性与复杂度

循环移位给出等价目标；Bluestein 恒等式计算原长度频谱；交点栈建立全部直线的最大值函数；凸性扫描给出实数最优点，相邻整数性质给出整数最优解。

FFT 的长度 $L<4n$，频谱计算及排序均为 $O(n\log n)$，包络扫描和常数个整数候选求值均为 $O(n)$。故

$$\boxed{O(n\log(n+1))\text{ 时间},\quad O(n)\text{ 空间}.}$$

这些是固定精度算术下的操作数。题目要求 $10^{-9}$ 的绝对或相对误差，实际实现应保留上述精度措施，并输出足够的小数位。
