# 双轨归档：RSK、双行形状与形式幂级数

来源：[QOJ 7875](https://qoj.ac/contest/1440/problem/7875)，2023 ICPC 合肥 B。比较基准为 `sources/public_tutorial_excerpt.pdf` 所摘录的原 PDF 第 7–8 页。采用经典 RSK 对应和对称函数恒等式，不把这些工具称为本次原创。本包最终范围为 $n\le10^6$、$1\le m=\sum a_i\le10^6$、$0\le a_i\le n$，使用此前选定的现场计算算法，不使用预存答案。

令 $m=\sum_i a_i$，忽略 $a_i=0$ 的类型，正计数类型数为 $r$。两条队列能够排序，当且仅当原序列能够拆成两个不下降子序列；等价于没有长度 3 的严格下降子序列。

## 1. RSK 把合法单词变成双行表

使用单词版本的 RSK：插入表 $P$ 行弱增、列严格增，内容为 $(a_i)$；记录表 $Q$ 是标准 Young 表。最长严格下降子序列的长度等于形状的行数，所以合法形状只有

$$\lambda=(m-k,k),\qquad 0\le k\le\lfloor m/2\rfloor.$$

给定形状后，$P,Q$ 可独立选择。双行形状的标准 Young 表数量由钩长公式得到

$$f_k=\binom mk-\binom m{k-1},$$

约定下标为负的二项式系数是零。

## 2. 指定内容的半标准表数量

定义

$$C(x)=\prod_{i:a_i>0}(1+x+\cdots+x^{a_i})=\sum_k c_kx^k.$$

从每种字符中选择 $b_i$ 个放入第二行，$0\le b_i\le a_i$、$\sum b_i=k$，不考虑列约束时方案数是 $c_k$。

精确的列约束由双行 Jacobi–Trudi 恒等式给出：

$$s_{(m-k,k)}=h_{m-k}h_k-h_{m-k+1}h_{k-1}.$$

提取内容单项式 $z_1^{a_1}\cdots z_n^{a_n}$。第一项的系数为 $c_k$，第二项为 $c_{k-1}$。因此插入表数量为 $c_k-c_{k-1}$，而不是不受限制的 $c_k$。

得到答案

$$\boxed{\sum_{k=0}^{\lfloor m/2\rfloor}(c_k-c_{k-1})
\left(\binom mk-\binom m{k-1}\right)}.$$

这也解释了两个边界：所有元素相同，只有 1 个合法序列；所有元素不同，答案为 Catalan 数。

## 3. 用对数和指数快速求乘积

只需求 $C$ 的前 $K+1$ 项，$K=\lfloor m/2\rfloor$。写成

$$C(x)=(1-x)^{-r}\prod_{i:a_i>0}(1-x^{a_i+1}).$$

令 $b_d=\#\{i:a_i+1=d,\ a_i>0\}$，则

$$[x^j]\log C(x)=\frac{r-\sum_{d\mid j}d b_d}{j},\qquad j\ge1.$$

枚举 $d$ 的倍数计算分子，取模乘 $j^{-1}$，在 $O(m\log(m+1))$ 内求出这些系数。再使用形式幂级数指数得到 $C$，最后线性求和。

零计数类型必须跳过：否则会错误地改变 $(1-x)^{-r}$ 的次数。

## 4. 指数算法与真实复杂度

已知 $f=\exp(h)\bmod x^s$，通过

$$f_{new}=f(1+h-\log f)\bmod x^{2s}$$

倍增。$\log f$ 使用 $f'/f$ 积分计算，多项式逆也用 Newton 倍增。代码只计算指数修正的高半部分。

每个精度为 $s$ 的阶段花费 $O(s\log(s+1))$，各阶段精度成几何级数。内部重新计算多项式逆也按几何级数求和，故总计为

$$O(n+m\log(m+1))\text{ 时间},\qquad O(n+m)\text{ 空间}.$$

PDF 没有单列最终复杂度；按其 $j,x,k$ 转移直接枚举，跳过零计数后最坏上界为 $O(n+m^3)$。即便先把 DP 整理成二次算法，仍可由这里的生成函数进一步改善。不能把“公开所有实现都是三次”当作结论。

采用固定字长 RAM 模型，模数为 998244353，模乘先转 64 位。本次代码已测试到 $m=10^6$；此时所有阶乘与积分分母都小于模数，所需 NTT 长度不超过 $2^{20}$，小于支持的 $2^{23}$。不能不检查变换长度就任意扩容。

代码：[src/std.cpp](src/std.cpp)，为单文件 C++17，不需要外部库。[src/brute.cpp](src/brute.cpp) 直接枚举多重集排列并检查严格下降三元组，是不依赖 RSK 的独立验证；[src/formula_reference.cpp](src/formula_reference.cpp) 朴素构建乘积并使用 Pascal 递推，检验多项式计算，但共享 RSK 公式，不冒充完全独立的数学证明。

## 5. 本包新增的独立插入 DP

`src/reference.cpp` 依据公开题解写出直接插入 DP。将原序列反转，转为禁止长度 3 的严格上升子序列；从小到大插入各类型的全部元素。

长度为 $s$ 时，状态 $f_j$ 记录最早出现上升二元组的第二个位置 $j$；若不存在则取哨兵 $j=s+1$。初始空串 $f_1=1$。

插入 $a$ 个新最大值。全部放在最前面时，状态变为 $j+a$。否则设最前面放了 $x<a$ 个，第一处非最前面的插入发生在原串第 $k$ 个位置之后，$1\le k<j$。新状态为 $x+k+1$。其余 $a-x-1$ 个最大值可分配到 $k,k+1,\ldots,j-1$ 这些空隙，方案数为

$$\binom{j-k+a-x-2}{a-x-1}.$$

这些位置限制恰好禁止新最大值成为上升三元组的第三项。直接枚举上述转移，跳过零计数类型，得到 $O(n+m^3)$ 时间、$O(n+m)$ 空间的独立参考。代码是本包依据 PDF 重新实现的参考，不冒充出题人原始源码。

## 6. 大结构核验与整数前提

`src/structured_reference.cpp` 对单类型使用答案 1，对两类型使用二项式系数，对全异使用 Catalan 闭式。对于 $q$ 种类型都出现 $d$ 次的结构，独立使用 $B(x)=(1+x+\cdots+x^d)^q$ 的微分恒等式：

$$k b_k=\sum_{j=1}^{\min(d,k)}((q+1)j-k)b_{k-j}.$$

它用短递推生成系数，不调用 NTT、Newton 或 FPS 指数；若另有一个单次出现的类型，乘以 $(1+x)$ 即可。这一路核验共享 RSK 最终计数式，与直接排列暴力和插入 DP 的独立性不同，验证记录中作了区分。

标准程序的所有模乘都先转为 64 位，最大的两个带偏移差值乘积小于 $4\times998244353^2<2^{63}$。合法输入的总量至多 $10^6$，因此读入累加的 `int`、数组下标和倍增长度均安全；输入校验器另用 64 位检查总量，避免恶意超范围输入造成累加溢出。程序没有递归 DFS 或深层递归，所有 NTT 与 Newton 操作均为迭代。

本次全部 20 个正式输入均运行 ASan/UBSan 标准程序；这些耗时不进入时限测量。精确覆盖和慢程序比较见 `../README.md` 与 `records/`。没有对本算法作理论最优或全局最优声明。
