## Problem Description

A deck contains $2n$ cards. Its ranks are $1,\ldots,n$, each occurring exactly twice. Process the cards in their given order, placing each card on top of one of at most **180 stacks**.

After all cards have been placed, the stacks must allow complete removal of every card using this operation: choose two different nonempty stacks whose top cards have equal rank, and remove both top cards simultaneously.

Output a stack assignment that makes complete removal possible. You need not output the removal sequence.

## Input Format

Read from standard input.

The first line contains $n$. The second line contains the $2n$ ranks $a_1,\ldots,a_{2n}$, in processing order.

## Output Format

Write to standard output.

Print one line containing $2n$ integers $c_1,\ldots,c_{2n}$. Card $i$ is pushed onto stack $c_i$, where $1\le c_i\le180$.

The output must contain exactly $2n$ integers. The checker directly verifies whether all cards in the resulting stacks can be removed; your stack labels need not match a reference answer. Any valid assignment is accepted. Unused stacks are allowed and require no additional output.

## Examples

Input:

```text
3
1 2 3 1 3 2
```

Output:

```text
1 1 1 2 2 3
```

## Explanation / Notes

The shown sample assignment produces stacks $[1,2,3]$, $[1,3]$, and $[2]$, listed from bottom to top. The other 177 stacks are empty. Remove rank 3 from stacks 1 and 2, rank 2 from stacks 1 and 3, and finally rank 1 from stacks 1 and 2.

Large main test decks are generated by random shuffling as specified below; additional valid boundary-structure cases are also included. You do not need to minimize the number of stacks; using at most 180 is sufficient.

## Constraints

- $1\le n\le5\times10^5$.
- There are exactly $2n$ input cards.
- $1\le a_i\le n$, with integer ranks.
- Each rank in $\{1,\ldots,n\}$ occurs exactly twice.
- Large main test decks are generated by **uniformly shuffling** the multiset $\{1,1,2,2,\ldots,n,n\}$; additional valid boundary-structure cases are included.
- Every official test instance is guaranteed to admit a valid assignment using at most 180 stacks.
- Each run receives one instance.
- Every output stack index must satisfy $1\le c_i\le180$.
- A removal must use two **different** stacks.
- Time limit: **2 seconds**. Memory limit: **256 MB**.
