# 格域边界：题解

本题要求构造，不要求最小化 $K$。下面给出标准程序使用的现场计算算法。它对 $N\le40$ 保证

\[
K/N\le45/37<1.25,
\]

因此满足题目要求。这个结论只是本实现的可证明上界，不代表理论最优或全局最优。

完整证明见同目录的 `worldmap_optimized_proof.md`。这里说明实现主线。

## 1. DFS 的基本性质

在无向图的 DFS 树中，每条非树边都连接祖先与后代。这允许我们用一段从根到当前点的祖先序列处理当前点的所有非树边。

标准程序同时构造若干张候选地图，最后选择边长最小的一张。

## 2. 匹配条带构造 A

从根开始向下处理 DFS 树：若一个非叶节点尚未匹配，就把它与一个儿子匹配。未匹配的顶点全部是 DFS 叶子，因此两两不相邻。

删去这些叶子后，在剩余树的一条直径上只走一次，其他树边往返。把游走序列放在方格的反对角线上。树边由相邻反对角线直接产生；每对匹配顶点再共用一个局部条带，加入它们与已处理顶点之间的非树边。

设匹配数为 $p$，未匹配叶子数为 $\ell$，删叶后树的直径为 $D$，则这个构造的精确边长为

\[
K_A=N+p-1-\lfloor D/2\rfloor.
\]

若 DFS 树高为 $H$，由 $N=2p+\ell$ 和 $\ell+D\ge H$ 得

\[
K_A\le\left\lfloor\frac{3N-H-1}{2}\right\rfloor.
\]

## 3. 祖先行构造 B

对深度为 $d$ 的顶点 $v$，根据根到 $v$ 的路径构造长度 $2H$ 的一行 $F(v)$。每个祖先层使用两个格子，按 $v$ 是否与这一层祖先相邻选择颜色。

这个定义保证：

- 行内不会产生非法接触；
- 父子对应的两行可以上下相邻；
- 每条非树边都在较深端点对应的行中水平出现；
- 行首为 $v$，行尾为根。

DFS 游走最后沿一条最深根叶路径前进且不返回，行数为 $L=2N-1-H$。将前缀旋转 $90^\circ$，与后缀在根色边界上拼接，可得

\[
K_{B1}=\max(2H,N-1+\lceil H/2\rceil).
\]

## 4. 扩大重叠并修补根边

选择所有非割点中度数最小的顶点作为根，记其度数为 $\delta$。删除该根后图仍连通，所以 DFS 根只有一个儿子。DFS 叶子也一定是非割点，而且其全部邻居都是祖先，因此 $1\le\delta\le H$。

在旋转拼接时多重叠一列或两列，可以分别得到

\[
K_{B2}=\max(2H,N-1+\lfloor H/2\rfloor),
\]

\[
K_{B3}=\max(2H,N-2+\lfloor H/2\rfloor).
\]

扩大重叠只可能删掉与根有关的边。设右上方剩余根色区域的高度为 $T=K-2H$，其中可以选出 $T(T+1)/2$ 个两两不相邻的棋盘格。把缺失根边的另一个端点分别放入这些格子，即可补回对应边，不会产生其他接触。

实现会扫描候选地图，只补实际缺失的根边；证明使用的充分条件是

\[
T(T+1)/2\ge\delta-1.
\]

## 5. 确定性长路径备用构造

若补边区太小，则使用非割点最小度 $\delta$ 构造一条至少含 $\min(2\delta,N-1)$ 条边的简单路径。

不断从路径两端加入路径外邻居。若两端都无法延伸，则两端都是非割点，度数至少为 $\delta$。当路径边数小于 $2\delta$ 时，抽屉原理保证可以用两条弦把整条路径闭成环。图连通且环尚未覆盖全部顶点，所以可从环上接入一个新顶点，路径长度严格增加。

强制一次新的 DFS 先沿这条路径走，代入构造 A，得到

\[
K_{A\text{-path}}\le
\left\lfloor\frac{3N-\min(2\delta,N-1)-1}{2}\right\rfloor.
\]

## 6. 上界与复杂度

标准程序取所有适用候选构造的最小边长。对

\[
2\le N\le40,\quad1\le H\le N-1,\quad1\le\delta\le H
\]

的全部 10660 个整数参数组合直接检查上述界，最大比值为

\[
\frac{45}{37}\approx1.216216<1.25.
\]

标准程序使用邻接矩阵。在单位成本 RAM 模型下，单个场景的时间复杂度为 $O(N^3)$，空间复杂度为 $O(N^2)$；最多 50 个场景时总时间为 $O(TN^3)$，峰值空间仍为 $O(N^2)$。所有下标与乘积在本题范围内使用 32 位有符号整数均安全。

## 7. 常见错误

- 只检查“图边都出现”，却没有禁止不存在的边在方格中接触。
- 忘记每种颜色必须至少出现一次。
- 把对角接触误认为相邻。
- 使用 $K\le\lceil5N/4\rceil$；题目要求的是向下取整。
- 默认每种颜色必须形成连通区域，这不是题目条件。
- 依赖某一种 DFS 邻接顺序而没有证明尺寸界。
