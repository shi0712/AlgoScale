# 题解：均味蛋糕

记 (M=max_i a_i)。

## 1. 固定美味度的可行条件

假设每个蛋糕的美味度都是 (b)，并且要制作 (K) 个蛋糕。

首先，数量最多的配料也必须能放入这些蛋糕中，且每个蛋糕中这种配料不能超过 (b) 份。因此必须有

[
Mle Kb.
]

另一方面，每个蛋糕都必须有某一种配料恰好出现 (b) 次，否则它的美味度会小于 (b)。第 (i) 种配料可以提供

[
\left\lfloor\frac{a_i}{b}\right\rfloor
]

个互不重叠的 (b) 份配料块，所以必须有

[
T(b)=sum_i\left\lfloor\frac{a_i}{b}\right\rfloorge K.
]

这两个条件也是充分的：取 (K) 个大小为 (b) 的配料块，每个蛋糕先放一个；由于每种配料都满足 (a_ile Kb)，剩余配料可以分摊到 (K) 个蛋糕中而不使任何一种配料在一个蛋糕中超过 (b) 份。每个蛋糕已有一个恰好为 (b) 的配料块，因此最终美味度恰为 (b)。

## 2. 每个询问只需检查一个 (b)

由容量条件，最小可能的美味度是

[
b_0=\left\lceil\frac{M}{K}\right\rceil.
]

函数 (T(b)) 随 (b) 增大而不增。因此若 (b_0) 都不能满足 (T(b_0)ge K)，更大的 (b) 也不可能满足；反之 (b_0) 满足时上面的充分性构造成立。

所以询问的答案等价于

[
T\left(\left\lceil\frac{M}{K}\right\rceil\right)ge K.
]

## 3. 预处理全部 (T(b))

令 (S(x)) 表示满足 (a_ige x) 的配料种类数。它可以通过频次数组的后缀和在 (O(N+M)) 时间内得到。

利用恒等式

[
\left\lfloor\frac{a_i}{b}\right\rfloor
=\sum_{tge1}[a_ige tb],
]

交换求和顺序可得

[
T(b)=sum_{x=b,2b,3b,ldotsle M}S(x).
]

于是对每个 (b=1,2,ldots,M) 枚举它的倍数即可求出 (T(b))。总迭代次数为

[
sum_{b=1}^M\left\lfloor\frac Mb\right\rfloor=O(M\log M).
]

读入所有询问后，用整数除法计算 (b_0)，直接查表回答。

## 4. 正确性证明

引理 1：固定美味度 (b) 时，存在合法分配当且仅当 (Mle Kb) 且 (T(b)ge K)。

必要性由容量限制和每个蛋糕必须拥有一个大小为 (b) 的配料块得到。充分性由先放置 (K) 个配料块、再分摊剩余配料的构造得到。

引理 2：对一个询问 (K)，只需检查 (b_0=lceil M/K
ceil)。

任意可行的 (b) 都满足 (bge b_0)。而 (T(b)) 单调不增，所以 (T(b_0)ge K) 当且仅当存在可行的 (b)。

引理 3：程序计算出的 `blocks[b]` 等于 (T(b))。

对每个 (b)，程序把所有 (x=tb) 的 (S(x)) 相加。根据上一节的恒等式，这正好是 (sum_ilfloor a_i/b
floor)。

定理：程序对每个询问输出正确。

程序计算 (b_0)，并根据 `blocks[b_0] >= K` 输出。由引理 2 和引理 3，这个条件与存在合法分配完全等价。

## 5. 复杂度

频次数组和后缀和耗时 (O(N+M))，倍数枚举耗时 (O(Mlog M))，每个询问 (O(1))。总时间复杂度为

[
O(N+M\log M+Q),
]

空间复杂度为 (O(N+M+Q))。程序使用 64 位整数保存 (K) 和 (T(b))。
