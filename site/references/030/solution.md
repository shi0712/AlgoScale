# Rolling For Days 题解

## 1. 用独立时钟描述抽卡过程

总卡片数为 $n$，类型数为 $m$。直接以各类型已收集数量为状态，需要 $\prod_i(b_i+1)$ 个状态，无法满足新范围。

给每张原始卡片一个独立的、速率为一的泊松时钟。卡片还在池中时，时钟响一次表示抽到它：还需要该类型就取走，否则放回。当前剩余 $R$ 张牌时，下一次响铃对应每张牌的概率都是 $1/R$，所以忽略响铃间隔后，正好是原题的随机过程。

令 $X_i(t)$ 表示类型 $i$ 中，在时刻 $t$ 前已经发生过第一次响铃的原始牌数。该类型最早响铃的前 $b_i$ 张牌会被收集，因此

$$\text{已收集数}=\min(X_i(t),b_i),\qquad
r_i(X_i(t))=a_i-\min(X_i(t),b_i)$$

是实际剩余数。类别未完成等价于 $X_i(t)<b_i$。

设全部完成时刻为 $T$，抽卡总次数为 $K$。在还未完成时，单位时间的期望抽卡次数等于剩余牌数，所以

$$\boxed{\mathbb E[K]=\int_0^\infty\mathbb E\left[\mathbf1_{T>t}\sum_ir_i(X_i(t))\right]dt.}$$

我们要求的是抽卡次数，不能直接把完成时间 $\mathbb E[T]$ 当成答案。

## 2. 固定时间时，各类型相互独立

令 $u=e^{-t}$。一张原始牌尚未发生第一次响铃的概率为 $u$，因此

$$\Pr(X_i(t)=x_i)=\binom{a_i}{x_i}(1-u)^{x_i}u^{a_i-x_i}.$$

各类型独立。设 $j=\sum_i x_i$，则联合概率为

$$\left(\prod_i\binom{a_i}{x_i}\right)(1-u)^ju^{n-j}.$$

对于固定 $j$，时间变量的部分完全一样。因此可以先按 $j$ 合并组合权重及剩余牌数，最后统一积分。

注意 $j$ 是“发生过第一次响铃的原始牌数”，并非收集数。某类完成后，它剩余牌的首次响铃仍会增加 $j$，却不会减少牌池；所以剩余牌数不是简单的 $n-j$。

## 3. 同时维护方案权重与剩余牌数

处理若干类后，设 $o\in\{0,1\}$ 表示已处理类别中是否至少有一类未完成。

- $f[j][o]$：所有对应选择 $x_i$ 的权重 $\prod_i1/(x_i!(a_i-x_i)!)$ 之和。
- $g[j][o]$：同样的权重，再乘这些类别的实际剩余牌数之和。

初始只有 $f[0][0]=1$，其他均为零。

加入一类大小为 $a$、需求为 $b$ 的卡片，枚举其第一次响铃数 $x\in[0,a]$。令

$$z=\frac1{x!(a-x)!},\qquad e=[x<b],\qquad r=a-\min(x,b).$$

对旧状态 $(j,o)$，新状态为 $(j+x,o\lor e)$：

$$f_{\text{new}}[j+x][o\lor e]\mathrel{+}=f[j][o]z,$$

$$g_{\text{new}}[j+x][o\lor e]\mathrel{+}=(g[j][o]+f[j][o]r)z.$$

第二式先将新类别的剩余牌数加到旧加权和，再乘新类别的权重。由归纳可知，两个数组始终符合定义。使用两层滚动数组即可。

$b=0$ 的类不会使 $o$ 变成一，但它永远留下 $a$ 张无用牌，仍会影响抽卡次数，不能直接删除。

## 4. 用 Beta 积分还原答案

处理完所有类别后，$o=1$ 恰好表示过程尚未完成。将前面省去的 $\prod_i a_i!$ 乘回，并用 $dt=-du/u$，得到

$$\mathbb E[K]=\left(\prod_i a_i!\right)
\sum_{j=0}^{n-1}g[j][1]\int_0^1(1-u)^ju^{n-j-1}\,du.$$

对 $0\le j<n$，反复分部积分可得

$$\int_0^1(1-u)^ju^{n-j-1}\,du=\frac{j!(n-j-1)!}{n!}.$$

于是答案为

$$\boxed{\operatorname{ans}=\frac{\prod_i a_i!}{n!}
\sum_{j=0}^{n-1}g[j][1]j!(n-j-1)!\pmod{998244353}.}$$

当 $j=n$ 时，每类都有 $x_i=a_i\ge b_i$，未完成状态不存在。这一项应直接排除，不能计算不存在的 $(-1)!$，即使相乘的 DP 值为零也不能访问负下标。

时钟模型与原抽卡过程等价；DP 合并的是固定时间下的精确组合权重；积分将瞬时抽卡速率累加成期望次数。因此最终公式正确。

## 5. 为什么复杂度只有 $O(n^2)$

设处理第 $i$ 类之前共有 $s_i=\sum_{h<i}a_h$ 张牌，转移次数为

$$O\left(\sum_i(a_i+1)(s_i+1)\right).$$

由于 $a_i\ge1$，有 $a_i+1\le2a_i$，而

$$\sum_i a_is_i=\frac{n^2-\sum_i a_i^2}{2}.$$

因此所有转移合计为 $O(n^2)$。清空滚动数组的 $O(nm)$ 也被 $m\le n$ 包含。总复杂度为

$$\boxed{O(n^2)\text{ 时间},\quad O(n)\text{ 额外空间}.}$$

$n\le2000$，所有阶乘下标都小于模数，可用一次快速幂求最高逆阶乘，再反向预处理。模乘使用 64 位，并在继续连乘前取模。

若所有 $b_i=0$，所有未完成状态都为零，算法自然输出零；若 $b_i=a_i$ 对每类成立，每次抽取都有效，答案为 $n$。这两个边界也能直接从原过程理解。
