# 格径叠乘：题解与实现审计

本包标准程序沿用对话中选定的“十一进制数位拆分 + 指数前缀和 + 周期组合数 + 高低位分块”现场计算算法。它不是预存询问答案表，也没有退回线性于 $c$ 的算法。以下给出一个可证明的复杂度上界，不主张理论最优或全局最优。

## 1. 初始路径数

每种移动都使 $x+y$ 增加 $2$，所以一条合法路径恰有 $n$ 次移动。前两类移动的使用次数必须相同。反过来，满足这一条件的长度为 $n$ 的移动类型序列会到达 $(n,n)$；由于坐标单调，不会先越界再返回。因此

$$a_n=[x^0](x^{-1}+1+x)^n.$$

这就是中心三项式系数。

设 $n=\sum_j n_j11^j$。在模 $11$ 的 Laurent 多项式环中，有

$$(x^{-1}+1+x)^n\equiv\prod_j(x^{-11^j}+1+x^{11^j})^{n_j}.$$

最低位因子的指数在 $[-10,10]$ 内，而其他因子的指数均为 $11$ 的倍数。要使总指数为 $0$，最低位因子的指数必须为 $0$。逐位重复这个论证，得到

$$a_n\equiv\prod_j a_{n_j}\pmod {11}.$$

直接展开低于 $11$ 次的多项式可得

$$(a_0,\ldots,a_{10})\bmod11=(1,1,3,7,8,7,9,8,7,4,10).$$

这些数全部非零。$2$ 在模 $11$ 下的幂依次遍历所有非零余数，阶为 $10$。令

$$w=(0,0,8,7,3,7,6,3,7,2,5),\qquad 2^{w_d}\equiv a_d\pmod {11}.$$

则令 $e_n=\sum_j w_{n_j}$，便有 $a_n\equiv2^{e_n}\pmod {11}$。代码中的两个长度为 $11$ 或 $10$ 的固定数组只是模数相关的数位权值和幂表，不是任何 $(n,c)$ 询问的答案表。

## 2. 把前缀积转为前缀和

乘法在指数上变成加法，所求答案是 $2^{E_c(n)}\bmod11$，其中 $E_c(n)$ 是对 $e$ 作 $c$ 次前缀和后的第 $n$ 项，指数只需模 $10$。

分别求模 $2$、模 $5$ 的结果，最后用中国剩余定理合并。不要在模 $10$ 下使用要求模数为素数的组合数公式。

补充 $e_0=0$，设 $d_i=e_i-e_{i-1}$。由于 $e$ 是 $d$ 的一次前缀和，

$$E_c(n)=\sum_{i=1}^{n}\binom{n-i+c}{c}d_i.$$

可通过对前缀和次数归纳证明该式。等价地，差分序列的生成函数需要乘以 $(1-x)^{-(c+1)}$。

## 3. 按十一进制数位展开差分

考虑位权 $q=11^k$ 的数位。它仅在 $i$ 为 $q$ 的倍数时改变。写成

$$i=(11t+r)q,\qquad t\ge0,\quad1\le r\le11.$$

该数位对 $d_i$ 的贡献为

$$\Delta_r=\begin{cases}w_r-w_{r-1},&1\le r\le10,\\-w_{10},&r=11.\end{cases}$$

因此

$$(\Delta_1,\ldots,\Delta_{11})=(0,8,-1,-4,4,-1,-3,4,-5,3,-5).$$

$r=11$ 对应数位从 $10$ 变成 $0$，不能省略。多个数位同时进位时，各位贡献直接相加。

定义（$N\ge0$）

$$F(N,Q)=\sum_{j=0}^{\lfloor N/Q\rfloor}\binom{N-Qj+c}{c}.$$

则

$$E_c(n)=\sum_{q=11^k\le n}\ \sum_{1\le r\le11,\ rq\le n}\Delta_rF(n-rq,11q).$$

同一层的 $Q=11q$ 相同，至多有 $11$ 个查询。$rq>n$ 的项不存在；标准程序在做无符号减法前先排除这些项。

## 4. 固定素数下的周期

以下固定 $p\in\{2,5\}$，所有组合数和答案都模 $p$。取最小的 $p$ 的幂 $M$，满足 **$M>c$**。

由 $(1+x)^M\equiv1+x^M\pmod p$ 取 $x^c$ 系数可知

$$\binom{t}{c}\equiv\binom{t\bmod M}{c}\pmod p.$$

$Q$ 是 $11$ 的幂，故与 $M$ 互质。余数 $(N+c-Qj)\bmod M$ 的一个周期长度为 $M$，并恰好遍历所有余数。设

$$L=\lfloor N/Q\rfloor+1=BM+\ell,\qquad0\le\ell<M.$$

一个完整周期的贡献是

$$\sum_{t=0}^{M-1}\binom tc=\binom M{c+1}\equiv
\begin{cases}1,&c=M-1,\\0,&c<M-1.\end{cases}\pmod p.$$

所以完整周期贡献为 $B[c=M-1]\bmod p$，再处理剩下的 $\ell$ 项。$c=M-1$ 的特殊分支是必要的；正式数据中的错误变体测试验证了省略它会被检出。

注意：周期 $M$ 为 $O(c)$，但标准程序**不会分配长度为 $M$ 的数组**，也不会枚举完整周期。

## 5. 高低位分块

写 $M=p^k$，取

$$H=p^{\lfloor k/2\rfloor},\quad K=M/H,\quad t=u+Hv,$$

其中 $0\le u<H,0\le v<K$。由

$$(1+x)^{u+Hv}\equiv(1+x)^u(1+x^H)^v\pmod p$$

可得

$$\binom{u+Hv}{c}\equiv\binom{u}{c\bmod H}\binom{v}{\lfloor c/H\rfloor}\pmod p.$$

记这两个权值分别为 $L_u,R_v$。代码 `makeWeights` 按 $p$ 进制逐位扩张数组：新加一位后，将旧数组分别乘以对应的一位组合数。所有层的数组长度之和为几何级数，因此总构造时间为 $O(H+K)$，不需要对每个位置做模数不可逆的除法。

## 6. 环形区间求剩余项

令

$$b=(N+c)\bmod M,\qquad A=(-Q)^{-1}\bmod M.$$

余数 $t$ 对应的周期内序号是

$$j=A(t-b)\bmod M.$$

只保留 $j<\ell$ 的余数。固定低位 $u$，令

$$z=A(u-b)\bmod M=z_0+Hz_1.$$

代入 $t=u+Hv$ 可得

$$j=z_0+H\big((Av+z_1)\bmod K\big).$$

所以 $j<\ell$ 等价于

$$(Av+z_1)\bmod K<\left\lfloor\frac\ell H\right\rfloor+[z_0<\ell\bmod H].$$

将右侧记作 `take`，它在 $[0,K]$ 内。因为 $A$ 与 $K$ 互质，可以将高位权值排列为

$$U_{Av\bmod K}=R_v.$$

对 $U$ 求模 $p$ 的前缀和。满足条件的下标恰好是从 $-z_1\bmod K$ 开始、长度为 `take` 的环形区间。把它拆为至多两个普通区间，即可 $O(1)$ 查询，乘以 $L_u$ 后累加。

枚举 $u=0,1,\ldots,H-1$ 时，$z$ 通过 `z += A; if (z >= M) z -= M;` 更新。只需一次减法，因为旧 $z$ 与 $A$ 都在 $[0,M)$。

这样，每层 `prepare(Q)` 用 $O(K+\log M)$ 时间，一次 `F` 查询用 $O(H)$ 时间。

## 7. 合并与完整正确性

由第 1 节，初始序列等于 $2$ 的数位权值和次幂。第 2 节将题目中的操作严格变成指数的重复前缀和；第 3 节将该指数展开为各数位的差分贡献。第 4–6 节逐项正确计算每个 $F$ 在模 $2$ 与模 $5$ 下的值。

设最终指数的两个余数为 $r_2,r_5$。令 $e=r_5$；如果 $e$ 的奇偶性不是 $r_2$，就令 $e\gets e+5$。此时 $e\in[0,9]$ 是唯一同时满足两个同余式的数，输出 $2^e\bmod11$ 即为答案。

因此标准程序对全部规定输入正确。

## 8. 真实复杂度与计算模型

使用 **64 位 word-RAM / 本题范围内定长整数运算为常数时间** 的模型。取模、乘法、除法等操作数均能由本实现的 64 位整数容纳。不将其解释为无限精度整数下的位复杂度结论。

记 $D=1+\lfloor\log_{11}n\rfloor$。更具体的每组上界为

$$O\left(\sum_{p\in\{2,5\}}(H_p+K_p)+D\sum_{p\in\{2,5\}}(K_p+11H_p+\log M_p)\right).$$

其中逆元使用迭代扩展欧几里得算法。由于 $M_p\le p(c+1)$，且 $K_p/H_p$ 为 $1$ 或 $p$，有

$$H_p\le\sqrt{p(c+1)},\qquad K_p\le p\sqrt{c+1}.$$

将 $11$ 视为固定进制，单个固定素数的上界可写成

$$O\big(p\sqrt{c+1}\,D\big)\text{ 时间},\quad O\big(p\sqrt{c+1}\big)\text{ 空间}.$$

本题只使用固定的 $p=2,5$，且合法输入 $c\ge1$，因此标准程序每组为

$$\boxed{O\big(\sqrt c(1+\log_{11}n)\big)\text{ 时间},\qquad O(\sqrt c)\text{ 空间}.}$$

多组询问顺序处理，总时间是各组复杂度之和，空间不是乘以 $T$。无需 FFT、递归或长度为 $c$ 的预处理表。

## 9. 扩大到 $c\le10^9$ 的实现审计

| 项目 | 最大值或适用条件 | 实现处理 |
|---|---:|---|
| 模 $2$ 的 $M$ | $2^{30}=1,073,741,824$ | 可存 `int` |
| 模 $5$ 的 $M$ | $5^{13}=1,220,703,125$ | 可存 `int` |
| $z+A$ | 严格小于 $2M$，可超过 `INT_MAX` | **将 `z` 改为 64 位** |
| 模 $2$ 的 $H,K$ 最大值 | $32768,32768$ | 动态数组 |
| 模 $5$ 的 $H,K$ 最大值 | $15625,78125$ | 动态数组 |
| 乘法 $A b$ | 小于 $M^2<1.5\times10^{18}$ | `1LL * A * b` |
| $N+c$ | 不超过 $10^{18}+10^9$ | 64 位 |
| 最大数位层 $q$ | $11^{17}=505447028499293771$ | 64 位 |
| 最大公差 $11q$ | $11^{18}=5559917313492231481$ | 64 位，仍小于 $2^{63}$ |
| 逆元 | $\gcd(11^k,p^r)=1$ | 只在模 $2$、$5$ 的幂下求逆 |
| 环形前缀和数组 | $K+1$ 项 | 右端点允许等于 $K$ |
| 递归 | 不使用 | 不存在递归栈深度问题 |

原小范围版本的 `int z` 在新范围下确有溢出风险，不能只修改常量上限。本包已经修正，并以 ASan/UBSan 及恢复旧类型的错误变体验证。差分和环形区间的减法可为负，最终会归一化到 $[0,p)$。

`std.cpp` 仍保留了 $c=0$ 的兼容分支，额外做了 $250$ 组兼容检查；但本题正式范围、正式数据和校验器均要求 $c\ge1$。变量 `Jprsj` 已保留。

## 10. 第二实现与独立验证的边界

`reference.cpp` 支持完整范围。它共享周期组合数归约，但使用逐项 Lucas 权值、Euler 定理求逆、排序后的加权余数坐标及二分区间查询，并用数位整块贡献而不是差分数组合并结果。其固定素数复杂度约为 $O(\sqrt c\log(c+1)(1+\log_{11}n))$，**它不是用于测时和出答案的标准程序**。

`brute.cpp` 使用二维网格 DP 计算初值，再直接执行前缀积，独立于数位分解和周期归约。`unit_tests.cpp` 还用直接组合数系数加权验证小 $n$、大 $c$，并用逐项 Lucas 枚举验证 `F`。

实际执行范围、逐文件结果、错误变体、sanitizer 和测时记录见 `records/` 及 `VALIDATION_REPORT.md`。本包没有在用户的目标 UOJ 沙箱实际部署；本地验证不能替代该步骤。
