# 角印棋盘：题解

## 1. 图模型

把原棋盘中每个点号方格建成一个顶点。把每个中心（加号或星号）拆成两个顶点
x0、x1，并在两者之间连一条内部边。

- 对于加号，两个副本都与中心上下左右相邻的所有点号方格连边；
- 对于星号，x0 只与左右相邻的点号方格连边，x1 只与上下相邻的点号方格连边。

这样一个中心的两个副本同时匹配到两个空格时，正好对应一个合法骨牌。
星号的两个副本被限制在横、纵两个方向，因此只能形成 L 形；加号可以选择
任意两个不同方向，既可形成 L 形也可形成 I 形。

设中心总数为 C，图的最大匹配大小为 ν。未使用的中心用内部边匹配，使用的
中心用两条外部边匹配。因此放置 k 个骨牌可以得到大小 C+k 的匹配。
反过来，如果最大匹配中某中心只有一条外部边，可以把它换成内部边而不减小
匹配大小；若两副本均未匹配，则可直接加入内部边，与最大性矛盾。故最大匹配
可以规范化为“内部边”或“两条外部边”两种状态，最优骨牌数为 ν-C。

## 2. 求最大匹配

图不是二分图：一个加号的两个副本和同一个相邻空格会形成三角形。因此使用
一般图最大匹配的 Micali--Vazirani 分阶段算法。实现中的 blossom 收缩使用并查
集维护花瓣集合。

令 N=nm。每个方格至多产生两个顶点，所以 V=O(N)；每个中心至多产生一条
内部边和八条外部边，所以 E=O(N)。实现采用带并查集路径压缩的保守复杂度

$$O(E\sqrt V\,\alpha(V))=O(N\sqrt N\,\alpha(N)),$$

空间复杂度为 O(V+E)=O(N)。这里的 α 是反 Ackermann 函数。复杂度模型按邻接
表、并查集和单位字操作计数。

## 3. 恢复输出

最大匹配规范化后，遍历每个中心：若两个副本分别匹配到空格，就取中心和这两个
空格作为一个骨牌；否则不取。最后按任意顺序给骨牌贪心分配小写字母。一个骨牌
只有三个方格、内部有两条公共边，至多与八个其他骨牌共边，所以 26 个字母足够。

## 4. 正确性要点

1. 图中的每条外部边只连接中心副本与原本的点号方格，故恢复出的骨牌不会覆盖非法
   方格。
2. 星号的方向限制保证恢复出的星号骨牌恰为 L 形；加号的任意两条不同外部
   边涵盖题面允许的两种形状。
3. 匹配保证不同中心使用的空格互不相同，故骨牌互不重叠。
4. 规范化最大匹配与骨牌方案之间保持匹配大小 C+k，因此恢复出的骨牌数达到
   最大值。
5. 染色只在共边骨牌之间禁止相同字母，所以输出满足字母约束。
