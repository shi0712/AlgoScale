# 海岸围界：题解与实现说明

本文说明本包实际使用的现场计算算法。标准程序是 `admin/src/std.cpp`，C++17 标准库、`long double`，不使用 Boost、预存答案或按输入查表。相对上一轮确认的 `no_boost.cpp`，仅将三个位置的 `fmal(a,b,c)` 改为普通的 `a*b+c`；几何候选、十二次以内的多项式消元、各阶导数分割点的保留、区间缩放、等速退化处理及 90 次迭代上界均不变。原版保留在 `baseline_fmal.cpp` 供对照。

这一常数优化的动机是：本次 x86-64 环境中，80 位扩展精度的 `fmal` 不是普通硬件 double FMA 的成本。取消软件融合操作会改变最后几位舍入，因此本包额外进行了原版对照和独立数值验证，而没有将其声称为逐位等价变换。不能为进一步加速而开启 `-ffast-math`。

## 一、几何候选为什么是这些形状

设海岸为 $y=0$，陆地在 $y>0$。总时间固定为 $t$ 时，所有价值系数为正，可以把剩余时间用于扩张边界；求最优值时使用完时间。

完全留在陆地时，等周不等式给出候选

$$A_0=\frac{V(vt)^2}{4\pi}.$$

这个圆可以向陆地方向放置，使起点在圆周上，故任何 $d>0$ 都可行。

对于跨岸区域，考虑平行于海岸的截线，将每一截面的区间居中排列。这个 Steiner 对称化保持两侧的面积，且不增加各半平面内的边界长度；可用先对有限折线对称化、再取极限来理解。跨岸形状在陆地的最高高度记为 $H$。当 $H\ge d$ 时，该形状的边界会经过高度 $d$，因此可以整体水平平移，使起点落在边界上。起点限制就转化为 $H\ge d$。

在某一种介质内部，对“价值 $-\lambda\times$ 时间”做局部法向变分，得到曲率为该介质单位面积价值乘速度再除以 $\lambda$。故陆地与水域边界分别为常曲率圆弧。记陆地圆弧半径为 $R$，水域圆弧半径为 $r$，则

$$VvR=Wwr.$$

因为价值严格为正，一段在海岸上的直线闭合边界可以向对应介质略微弯曲，得到一阶面积增益，而额外长度仅为二阶；因此它不是遗漏的非退化最优形态，退化情形用极限处理。

对称化、常曲率条件和高度约束合起来给出两种跨岸候选：

1. $H=d$：起点限制生效，陆地部分是两段半径相同的圆弧，在最高点允许形成尖角；水域是一段圆弧。
2. $H>d$：高度约束不生效，陆地最高点必须光滑，两段陆地圆弧合成一整段圆弧；再水平平移使起点位于边界上。

这不是假设最优区域整体是凸集，也不是假设起点总在最高点。介质交界处允许折角；后一种候选尤其不能省略。

## 二、无量纲参数与高度受限候选

定义

$$h=\frac vw,\quad q=\frac{vV}{wW},\quad p=\frac{vt}{2d},\quad r=qR.$$

设右半侧陆地圆弧在最高点和海岸处向下转的切线角分别为 $\alpha,\beta$；用 $\gamma\in[0,\pi]$ 表示相应的水域接岸角，水中完整圆弧的圆心角为 $2(\pi-\gamma)$。合法尖角满足 $0\le\alpha\le\pi/2$。

沿海岸移动交点的边界变分条件为

$$\frac{\cos\beta}{v}=\frac{\cos\gamma}{w}.$$

令

$$c=\cos\gamma,\ s=\sin\gamma,\quad
u=\sqrt{1-h^2c^2},\quad z=u-qs.$$

由共同的海岸半弦长得到

$$\cos\beta=hc,\quad \sin\alpha=z,\quad
D=\sqrt{1-z^2}-hc,\quad R=\frac dD.$$

两种介质中的总时间对应

$$B=\beta-\alpha+qh(\pi-\gamma),\qquad
\frac{2R}{v}B=t.$$

于是求解

$$F(\gamma)=B-pD=0.$$

每个合法根的价值可以简化为

$$A=VR\left(\frac{vt}{2}-dz\right).$$

也可以独立用面积验证。记 $\delta=\beta-\alpha$，海岸半弦长 $x=R(\sin\beta-\sin\alpha)$，则

$$S_L=dx+R^2(\delta-\sin\delta),$$
$$S_W=q^2R^2\bigl(\pi-\gamma+\sin\gamma\cos\gamma\bigr).$$

这里的陆地面积是一个三角形加两个圆弓形。`reference_scan.cpp` 使用这两个直接面积表达式，而不是标准程序的简化价值表达式。

## 三、合法区间、快捷返回和光滑候选

若 $p\le1$，往返海岸就已用完可用时间，直接返回 $A_0$。

另一个可返回圆的条件是 $h\ge1$ 且 $q\ge1$。此时 $u^2\le s^2$ 且 $qs\ge s$，故 $z=u-qs\le0$；除退化相等情形外不存在合法的高度受限跨岸驻点。光滑跨岸候选同样不改善陆地圆，退化边界由圆包含。

其余情况下，由 $|hc|\le1$、$0\le z\le1$ 得出：

- $h<1,q>1$：$s\le\sqrt{(1-h^2)/(q^2-h^2)}$，所以 $\gamma$ 属于靠近 $0$ 和 $\pi$ 的两个区间。
- $h>1,q<1$：$c^2\le(1-q^2)/(h^2-q^2)$，所以 $\gamma$ 属于中间的一个区间。
- 其他未提前返回的情况：使用整个 $[0,\pi]$。

若高度约束不生效，最高点光滑，有 $\alpha=0$，即 $z=0$。解得

$$c^2=\frac{1-q^2}{h^2-q^2}.$$

分母非零、右边属于 $[0,1]$ 且满足 $h^2c^2\le1$ 时，分别枚举正负平方根。此时 $B=\beta+qh(\pi-\gamma)$，令 $R=vt/(2B)$，检查陆地高度 $R(1-hc)\ge d$，再计入候选价值 $VvRt/2$。

## 四、不能直接对整个区间二分或三分

$F$ 不保证全区间单调，也不保证只有一个极值。算法先找出包含所有驻点的有限分割点，再在各段检查符号并二分。允许多加分割点，不允许漏掉改变单调性的驻点。

令

$$K=qu-h^2s,\qquad M=psu-s+qu.$$

对 $F$ 求导并移项、平方，可以得到驻点的必要条件

$$h^2(1-z^2)M^2-(1-s^2)K^2(pz-1)^2=0.$$

又因为

$$u^2=1-h^2+h^2s^2,$$

将所有 $u^2$ 消去后，左边可写成 $A(s)+uC(s)$；再次平方消去 $u$，得到

$$P(s)=A(s)^2-(1-h^2+h^2s^2)C(s)^2.$$

$P$ 的次数不超过 $12$。平方带来的伪根只会增加分割点，没有必要再做繁琐的筛除。将每个 $s$ 映射到 $\arcsin s$ 与 $\pi-\arcsin s$，并加上区间端点、$\pi/2$。

低次多项式通过递归求导数来划分：导数的根把原多项式分为单调段，异号段用二分找根。实现保留各阶导数的分割点，而不只返回最高阶多项式的异号根，因此数值上逼近重根的位置也会成为候选分界。每个分割点本身还会单独检查是否满足 $F=0$。

## 五、数值实现的关键点

1. **区间缩放。** 当合法 $s$ 区间很窄时，使用 $s=s_0+s_1x$、$x\in[0,1]$ 构造多项式。否则在接近端点的区域求根会损失大量有效数字。
2. **等速退化。** 当 $h=1$ 时不套一般展开式。令 $a=1-q$，直接使用代码中的三次多项式，以避免高阶项相互抵消。
3. **有理化。** 当 $hc\ge0$ 时，用
   $$D=\frac{qs(u+z)}{\sqrt{1-z^2}+hc}$$
   计算高度分母；这与直接作差等价但更稳定。
4. **角差。** 用 `atan2` 的正弦、余弦表达式计算 $\beta-\alpha$，避免两个接近的反三角函数值直接相减。
5. **计算模型。** 本次目标是 Linux x86-64 的 GCC，`long double` 使用至少 64 位有效二进制位。不能无检查地移植到 `long double` 等同于 `double` 的平台。
6. **迭代和筛选。** 二分上界为 90 次；浮点中点不再变化时退出。根代回时间方程检查，拒绝不满足时间限制的伪候选。所有反三角函数输入都作边界钳制。
7. **舍入。** 最后输出 `fixed << setprecision(3)`，中间不做三位小数舍入。

## 六、正确性结论及数值验证的边界

在精确几何与可可靠判符的数值求根模型下，前面的对称化和变分条件把最优值归入陆地圆、光滑跨岸候选或高度受限方程的合法根。驻点分割确保每个单调区间中的根被枚举；计算并取这些候选的最大值，即得到最优值。

实际机器程序采用固定精度。上面的论证不是“任意接近重根、任意长度实数文本也可严格正确舍入”的区间算术证明；保留导数分割点也不等同于经过形式化认证的实根隔离。本包采用明确的输入文本精度，保存了已执行的数值对拍、边界检查、直接公式和独立二维几何搜索记录。不能把有限对拍说成对全部实数输入的穷尽证明。

独立参考包括：

- `reference_scan.cpp`：密集角度扫描加逐段二分，无多项式消元，使用直接圆弓形面积；有限分辨率意味着它不是无条件的全局证明器。
- `reference_geometry.py`：直接以弦长、陆地圆弧半角、陆地/水域长度分配为变量做二维优化，不使用折射条件、$F$ 方程或消元多项式。它提供独立数值证据，不负责生成正式答案，也不声称差分进化保证全局最优。
- 均匀介质与不能围出水域等情况使用独立高精度十进制圆公式核对。

## 七、真实复杂度和扩大范围后的检查

以固定机器字、固定输入文本精度、固定 90 次迭代上界和固定三位小数输出为模型：每组只有六个数，多项式次数最多 12，候选数量与递归深度均有与 $T$ 无关的常数上界，因此总时间为 **$O(T)$**，标准程序额外空间为 **$O(1)$**。

若显式引入求根目标误差 $\varepsilon$，并假设根可分离且工作精度足以可靠判符，则固定次数多项式及有限区间的二分迭代量可写作 $O(T\log(1/\varepsilon))$。这个式子不是任意精度实数运算的位复杂度结论，也不包含为处理任意病态输入而提升工作精度的成本。

$T$ 上限调整为 $10^5$ 后，程序仍逐行计算、逐行输出，不保存全部询问。计数器 `int` 足够；多项式只随固定次数分配，递归不随 $T$ 增深。本题没有整数模运算、逆元或按 $T$ 索引的固定数组。输入校验器使用整数缩放检查至多九位小数，最大中间整数远小于 64 位整数上限。没有仅通过增大一个数组常量来适配新范围。

这里的 $O(T)$ 是本对话算法在上述模型下的复杂度陈述，**不宣称是理论最优或目前全局最优**。十万组非平凡几何问题的常数仍然明显；实际时限以本包保存的完整进程 CPU 测量为准。
