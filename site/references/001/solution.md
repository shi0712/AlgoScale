# 双端归约：题解与实现说明

本包标准程序沿用对话中确定的现场计算算法：**确定性基数排序、最大起点动态规划、欧拉迹构造**。单组时间、空间均为 $O(nm)$，并输出全部操作。本说明不给出算法下界，也不把这一上界称作理论最优或全局最优。

## 1. 先处理边界

每次操作保持全序列的异或值。若 $\bigoplus A\ne\bigoplus B$，直接判定不可行。

若 $n=m$，只检查两个线性序列是否逐项相等，不能允许循环移位。若 $m=1$，总异或相等就是充分条件，连续执行操作 $1$ 即可。

以下只讨论 $2\le m<n$，且总异或相等的情况。

## 2. 在环上观察分界点

将原序列的下标改成 $0,\ldots,n-1$，把它看成一个环，并在相邻元素之间设置分界点。当前线性序列的首尾分界点叫作游标。

操作 $1$ 沿顺时针方向跳过一个分界点并删除它，停在下一个分界点；操作 $2$ 沿逆时针方向做同样的事情。删除分界点就是合并相邻的两段，合并后的值为两段异或值的异或。

因此，最终元素对应原环上非空连续段的异或。把 $A$ 复制一遍后，一组候选分段可以写成

$$
s=x_0<x_1<\cdots<x_m=s+n,\qquad 0\le s<n.
$$

第 $i$ 段的异或值必须为 $b_i$，其中 $b$ 从 $1$ 开始编号。设段长 $L_i=x_i-x_{i-1}$，并定义

$$
F(x)=\begin{cases}x,&x\le n,\\2n-x,&x>n.\end{cases}
$$

### 分段可达定理

上述异或值正确的分段可达，当且仅当以下两个条件同时成立：

**模条件：** 存在 $d\in\{1,2\}$，使所有 $1\le i\le m$ 满足

$$F(x_i)-F(x_{i-1})\equiv d\pmod3.$$

**单元素段条件：** 所有 $L_i=1$ 的段，在最终的线性段序列中形成一个连续区间。它们可以不存在，但不能分成两段，也不能把首尾两端视为一个线性区间。

这里的“线性”很重要：即使单元素段在环上相邻，也不能任意选择最终序列的首尾分界点。

## 3. 必要性的证明

### 3.1 模 $3$ 不变量

在最终保留的首尾分界点处切开环。设当前仍有 $k$ 段，游标是第 $h$ 个分界点。分界点按当前顺序编号为 $0,\ldots,k$；两个端点是切口的两份表示。定义

$$
G_h(j)=\begin{cases}j,&j\le h,\\2h-j,&j>h.\end{cases}
$$

最终切口不会被删除。在不跨切口的操作 $1$ 中，删除编号 $h+1$ 的点，游标变为新编号 $h+1$。对剩余分界点重新编号后，其 $G$ 值与原值之差为 $0$ 或 $3$。类似地，操作 $2$ 后差值为 $0$ 或 $-3$。

如果游标在切口处，需要把其表示从 $h=0$ 切换成 $h=k$，或者反向切换，那么所有 $G$ 值同时取反。因而每个保留分界点的模 $3$ 标号，只可能经历整体取反，不会发生独立变化。

初始时，切口为原坐标 $s$，游标为原坐标 $0$ 的对应副本。对原坐标 $x$，上述标号是 $F(x)-s$。最终游标回到切口，标号则是 $i$ 或 $-i$。于是对包括两个切口副本在内的所有 $i$，存在统一的 $d\in\{1,2\}$ 使

$$F(x_i)-s\equiv id\pmod3,$$

相邻两式相减就是模条件。

### 3.2 单元素段必须连续

把参与过任意一次合并的原元素称为“已触及”。第一次操作后，已触及元素构成环上的一个连续区间，游标在它的边界上。

继续执行任意操作时，新触及的元素只能与这个区间相接；游标仍位于已触及区间与未触及区间的分界处，直到所有元素都已触及。因此，未触及的原元素始终构成一个连续区间，最终游标不能落在其内部。

最终长度为 $1$ 的段恰好由未触及的单个原元素组成。故这些段必须在最终线性序列中连续。

## 4. 充分性与操作构造

### 4.1 三步缩短一个目标段

操作串 `112` 把游标右侧的前四个当前元素合并为一个，并使游标回到原分界点。`221` 是左侧版本。

只要这些元素属于同一个目标段，就可以安全使用上述操作，使该目标段的当前长度减少 $3$，而不删除目标段的端点。

对不包含初始游标内部的普通目标段，模条件保证其长度不为 $0\pmod3$。从它的某个端点出发，可以按下表安排穿过该段的次数：

| 当前原始段长 | 穿过次数 | 具体实现 |
|---|---:|---|
| $L=1$ | $0$ | 不触及它 |
| $L\equiv2\pmod3$ | $1$ | 每次减 $3$ 直到长度 $2$，再用一步穿过并合成一个元素 |
| $L>1$ 且 $L\equiv1\pmod3$ | $2$ | 先缩到 $4$，用两步第一次穿过，留下长度 $2$；第二次穿过时用一步完成 |

每次穿过都从该段的一个目标分界点到另一个目标分界点，不会越过目标段。

### 4.2 初始游标位于目标段内部

这种目标段至多有一个。设游标到其左、右端点的当前长度分别为 $x,y$。先在两侧分别使用 `221`、`112`，使 $1\le x,y\le3$。

模条件给出 $x-y\equiv d\pmod3$，所以 $x\ne y$。接下来只需常数种处理，把该段保留为长度 $2$，并把游标移动到一个目标端点：

| $(x,y)$ | 操作串 | 游标所在端点 |
|---|---|---|
| $(1,2)$ | `1` | 右 |
| $(1,3)$ | `12` | 左 |
| $(2,1)$ | `2` | 左 |
| $(2,3)$ | `211` | 右 |
| $(3,1)$ | `21` | 右 |
| $(3,2)$ | `212` | 左 |

这些只是固定大小局部状态的构造公式，不是输入答案表。它们不涉及 $A,B$ 的数值，主算法仍为每组输入现场执行 DP。

标准代码的 `finish` 表存储上述串再加最后一次合并的版本，但实际只执行到倒数第二个字符，正好得到本表中的操作串。

### 4.3 转成欧拉迹

把最终分界点作为顶点，每个目标段作为相邻顶点间的一条边，边的重数为上表中的穿过次数：$0,1,2$。特殊段预处理后长度为 $2$，重数为 $1$。

考察普通段。位于原坐标 $n$ 之前的段有 $L\equiv d\pmod3$，之后的段有 $L\equiv-d\pmod3$。重数的奇偶性仅取决于长度是 $1$ 还是 $2\pmod3$：前者为偶数，后者为奇数。

若初始游标本来就是目标分界点，边重数奇偶性只可能在初始游标与最终切口处发生改变。因此，这两个顶点是仅有的奇度顶点；若二者相同，则所有顶点都是偶度。

若初始游标位于特殊段内，局部处理在 $d=1$ 时停在左端，在 $d=2$ 时停在右端。代入特殊边重数为 $1$ 后，同样得到“当前游标与最终切口是仅有的奇度顶点，或者二者相同且全部为偶度”的结论。

重数为 $0$ 的边恰好是单元素段。由单元素段连续的条件，所有非零重数边连通；最终切口和当前游标都在该连通部分中。当两游标重合时，若切口两侧都是零重数边而还有非零边，就会违反单元素段在线性序列中连续的条件。

所以存在从当前游标到最终切口的欧拉迹。用非递归 Hierholzer 算法求出该迹，再将每次经过边替换为第 4.1 节的操作即可。$m=2$ 时，两条环边是连接相同端点的不同平行边，必须用边编号区分；标准程序已经如此处理。

走完以后，每段都恰好合成为一个元素，游标位于指定切口，得到目标线性序列 $B$。每个真实操作都把长度减少 $1$，因此操作数恰为 $n-m$。这同时证明了分段可达定理的充分性。

## 5. 不枚举起点的动态规划

令 $P$ 为复制后的 $A$ 的前缀异或。固定 $d\in\{1,2\}$，从首尾分界点的模条件得到

$$md\equiv F(s+n)-F(s)=n-2s\pmod3,$$

即

$$s\equiv r=(2n+md)\bmod3.$$

因此，只考虑模 $3$ 为 $r$ 的起点；第 $i$ 个分界点 $v$ 必须满足

$$F(v)\equiv r+id\pmod3.$$

设 $dp_i[v][z]$ 是已经匹配前 $i$ 个目标元素、结束于分界点 $v$、阶段为 $z$ 的所有路径中，**最大的起点坐标**。不可达记为 $-1$。

阶段有三种：

- $z=0$：尚未开始单元素段的连续区间；
- $z=1$：正在该区间中；
- $z=2$：已经离开该区间，以后不能再选长度为 $1$ 的段。

初始状态是 $dp_0[s][0]=s$，其中 $0\le s<n$ 且 $s\equiv r\pmod3$。

假设上一分界点为 $u$，当前分界点为 $v$。第 $i$ 段匹配 $b_i$ 等价于

$$P[u]=P[v]\operatorname{xor}b_i.$$

长度为 $1$ 时，只需检查 $u=v-1$，允许状态 $0\to1$ 或 $1\to1$。

长度至少为 $2$ 时，允许 $0\to0$、$1\to2$、$2\to2$。按 $v$ 递增扫描，将 $u=v-2$ 的状态加入以 $P[u]$ 分类的最优值；每类分别维护状态 $0$ 的最大起点、状态 $1/2$ 合并后的最大起点。这样每个状态只处理常数次。

保存最优值对应的前驱，就能最终恢复全部分界点。

### 为什么只保留最大的起点不丢解？

设当前考察终点 $v=s+n$。若 DP 记录的最大起点为 $s'\ge s$，匹配全部目标段意味着

$$P[v]\operatorname{xor}P[s']=\bigoplus B.$$

又因为预先保证了总异或相等，且长度为 $n$ 的环形窗口都含原序列恰好一次，

$$P[v]\operatorname{xor}P[s]=\bigoplus A=\bigoplus B.$$

所以 $P[s']=P[s]$。二者也都模 $3$ 为 $r$。

把恢复出的第一段左端点从 $s'$ 向左延长到 $s$，第一段异或值和模条件都不改变。如果第一段原来长度为 $1$，这只会移除单元素连续区间的第一个元素，不会把它分裂成两个区间。因此，延长后的合法分段恰好覆盖 $n$ 个原元素。

所以终点 $v\in[n,2n-1]$ 的判定条件只需

$$\max_z dp_m[v][z]\ge v-n.$$

这个“最大起点 + 向左延长”的性质消除了额外枚举起点的 $n$ 倍复杂度。

## 6. 确定性查询，不用哈希

转移需要查询某个 $P[v]\operatorname{xor}b_i$ 是否等于某个前缀异或值，以及它对应的类别编号。

标准程序离线建立所有 $P[v]$ 及所有查询值的记录，总量为 $2n(m+1)$。用四趟、每趟 $8$ 位的基数排序对这些不超过 $30$ 位的值排序。同值记录相邻后，只给出现过真实前缀值的类别分配编号，其余查询置为无效。

此后每次 DP 查询都是数组访问。既没有随机哈希冲突，也没有平衡树查询的对数因子。

## 7. 正确性总结

总异或判定及两个边界分支正确。对其余输入，分段可达定理刻画了所有可达的目标分段。DP 枚举所有符合该定理及段异或要求的分界点路径；最大起点压缩与第一段延长保持可行性，所以 DP 成功当且仅当存在可达分段。欧拉迹构造将恢复出的分段实现为恰好 $n-m$ 次合法操作。

因此，标准程序给出的 `Yes`、`No` 及操作方案均符合题意。

## 8. 复杂度、计算模型与放大范围审计

采用固定宽度整数的 word-RAM 模型：本题元素为 $30$ 位整数，C++ 使用 `uint32_t`，一次异或、整数比较及合法数组下标访问为常数时间。四趟基数排序的基数固定为 $256$。

单组记录建立与排序为 $O(nm)$，两种 $d$ 的 DP 共 $O(nm)$，恢复与构造为 $O(n)$。总时间为 **$O(nm)$**，总空间为 **$O(nm)$**；$n=m$ 或 $m=1$ 的直接分支实际仅需 $O(n+m)$ 时间。整个文件顺序处理数据组，时间为 $O(|c|+\sum nm)$，空间为 $O(|c|+\max nm)$；$|c|$ 是仅作标识的十进制字符串长度。如果字宽不固定，不能直接把任意精度整数的运算及排序代价视为常数。上述读取代价按通常无冗长前导零的十进制表示估算；若输入允许任意长元数据或冗余前导零，还须计入实际输入字符数。

本版新增每个输入文件的 $S=\sum_i n_i m_i\le4\times10^6$。所有组都计入，包括 $n=m$ 与 $m=1$，因此文件算法工作量为 $O(S)$，而不是 $O(t\max_i(n_i m_i))$ 的独立最坏情况叠加。元数据 $c$ 的读取另计。该限制没有改变单组算法或构造，也不豁免预先发现无解的数据组。

对 $n,m\le2000$，已经逐项检查：

| 项目 | 最大规模或处理方式 |
|---|---|
| 真正进入 DP 的最大 $m$ | $1999$；$m=n$ 已提前处理 |
| 双倍长度 $N$ | $4000$ |
| 基数排序记录数 | $8,000,000$ |
| 查询编号数组元素数 | $7,996,000$ |
| 前驱数组元素数 | $23,988,000$ |
| 前驱状态编码 | 最大不到 $12,000$ |
| 排序桶计数 | 不超过 $8,000,000$，32 位有符号整数安全 |
| 元素运算 | 仅使用无符号 32 位异或，结果仍小于 $2^{30}$ |
| 操作数与构造栈 | 不超过 $1999$ 次操作；欧拉迹用显式栈，无深递归 |
| 取模与除法 | 模数恒为 $3$，无逆元；构造中的除 $2$ 只作用于 $2$、$4$ |

在本次 x86-64 ABI 中一个排序记录为 $8$ 字节。排序阶段两份记录数组约占 $128,000,000$ 字节；它们释放后才进入大前驱数组阶段。不能把两个阶段的峰值相加，但也不能把理论活跃分配量直接当成进程 RSS，因为分配器可能保留已释放内存。

本次总规模限制版正式测时进程的最大 `ru_maxrss` 为 $126748$ KiB，约 $123.777$ MiB，低于配置的 $256$ MB。本次全部 25 个正式文件均完整通过 ASan/UBSan；逐点记录见管理员验证报告。没有用预存输入答案替代现场算法。

## 9. 独立参考及验证

`solutions/brute.cpp` 直接枚举两种操作，不使用环分段定理、模条件或最大起点 DP。它的时间上界为 $O(n2^{n-m})$，保存递归链上的序列需要 $O(n(n-m))$ 空间；程序明确限制 $n-m\le20$，正式答案生成中只用到不超过 $12$ 的差值。

其余正式输入的答案来自可逐步模拟的操作证书，或可以独立验证的不可能性证书。特别地，如果所有 $a_i$ 在某个二进制线性函数下为 $0$，则之后每个元素都仍为 $0$；只要某个 $b_i$ 的函数值为 $1$ 就不可能。生成器还让两处违例相消，使这些例子的总异或依然相等。

正式答案的生成不调用标准程序。所有标准程序输出均与这些独立答案比较，并对每个 `Yes` 逐步模拟。小规模还有完整状态枚举及独立的符号原子分段枚举对拍；具体数量以 `logs/` 中本次执行记录为准。

### 总规模累加审计

校验器以 `long long sum_nm` 和 `sum_nm += 1LL*n*m` 累加，并在超过 `4000000LL` 时拒绝输入。不是只检查每组乘积，也不因零次操作或快速判 No 而跳过计数。即使忽略提前拒绝，旧范围下 1000 组乘积之和也可能达到 4,000,000,000，超过有符号 32 位，因此这里明确使用 64 位累加。校验器回归包含 3,999,999、4,000,000、4,000,001 以及 t=1000 的合法/非法联合边界。
