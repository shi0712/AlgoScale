# 排列双刻度：题解与实现说明

改编自 [QOJ 8956](https://qoj.ac/problem/8956)，使用[讨论 2612](https://qoj.ac/problem/8956/discussion/2612) 中的联合生成函数换基思路。所求统计量确实是超过数与降低数。实际 C++17 提交代码为独立的 `src/std.cpp`，采用现场 Stirling/Eulerian 建表、快速平移与多点求值。

## 1. 联合生成函数与换基恒等式

记

$$H_n(x,y)=\sum_{p\in S_n}x^{\operatorname{exc}(p)}y^{\operatorname{des}(p)}.$$

记 $c(j,i)$ 为**有符号第一类 Stirling 数**，满足
$c(0,0)=1$、$c(j,i)=c(j-1,i-1)-(j-1)c(j-1,i)$。

记 $A_i(x)=\sum_{p\in S_i}x^{\operatorname{des}(p)}$ 为 Eulerian 多项式，$A_0(x)=1$。其系数递推是

$$[x^k]A_i=(k+1)[x^k]A_{i-1}+(i-k)[x^{k-1}]A_{i-1}.$$

采用 Foata–Han 超过数、降低数联合生成函数的以下换基形式（这一统计恒等式是算法的组合基础）：

$$\frac{H_n(x,y)}{(1-y)^{n+1}}=\sum_{r\ge0}C_{n,r}(x)y^r,$$
$$C_{n,r}(x)=\sum_{j=0}^{n}\frac{\binom nj}{j!}\sum_{i=0}^{j}c(j,i)r^iA_i(x)(1-x)^{j-i}.$$

所有式子在有理系数形式幂级数中解释，随后在分母可逆的有限域中计算。该恒等式来自将联合生成函数中的下降阶乘按
$z(z-1)\cdots(z-j+1)=\sum_i c(j,i)z^i$
展开；下面的算法只需这个明确形式。它不是关于逆排列降低数的恒等式。直接全排列暴力作为独立验证，避免混淆统计量。

交换 $i,j$ 求和次序，定义

$$B_i(z)=\sum_{j=i}^{n}\binom nj\frac{c(j,i)}{j!}z^{j-i},\qquad D_i(x)=A_i(x)B_i(1-x).$$

于是

$$\boxed{C_{n,r}(x)=\sum_{i=0}^{n}r^iD_i(x)}.$$

问题因此分成两阶段：先得到所有 $D_i$，再对其系数矩阵转置并求值。

## 2. 用卷积做多项式平移

二次时间构建 Stirling、Eulerian 表和阶乘。假设 $B(z)=\sum_{j=0}^d b_jz^j$，则

$$[x^k]B(1-x)=\frac{(-1)^k}{k!}\sum_{j=k}^{d}b_jj!\frac1{(j-k)!}.$$

把 $b_jj!$ 反转，与逆阶乘序列卷积，就能一次求出所有系数。对每个 $i$ 先这样求 $B_i(1-x)$，再与 $A_i(x)$ 卷积，得到 $D_i$。逐项二项式展开会产生三次耗时，应使用上述整体平移。

对 $n>0$，$D_0=0$；对 $i\ge1$，$D_i$ 次数至多 $(i-1)+(n-i)=n-1$，所以只存 $x^0$ 至 $x^{n-1}$。

## 3. 转置并多点求值

固定超过数 $a$，令

$$E_a(t)=\sum_{i=0}^{n}[x^a]D_i(x)t^i.$$

需要的序列恰为 $C_a[r]=E_a(r)$，$0\le r<n$。使用节点 $0,1,\ldots,n-1$ 的公共乘积树与余式树；乘积树和各节点反转多项式的逆可以复用。逐点 Horner 会使此步骤退回三次复杂度。

由于只输出降低数 $b<n$，最后仅需

$$[x^ay^b]H_n=\sum_{r=0}^{b}C_a[r](-1)^{b-r}\binom{n+1}{b-r}.$$

每行与核 $K_j=(-1)^j\binom{n+1}{j}$ 卷积，取前 $n$ 项输出。形式幂级数的低次系数不依赖更高的 $r$，因此不用生成无限序列。

上述各步骤分别是联合恒等式的换序、等价平移、精确多点求值和乘回 $(1-y)^{n+1}$，所以输出的每一项都是所求排列计数。

## 4. 任意给定质数下的快速卷积

$M$ 不一定支持足够长的 NTT。若 $M=998244353$ 直接用该模数；其他情况用三个辅助素数

$$167772161,\quad469762049,\quad754974721$$

分别做 NTT，再用 CRT 恢复非负整数卷积并对 $M$ 取模。这里恢复的是模 $M$ 的标准代表元之间的整数卷积，因而其系数不超过 $L(M-1)^2$，其中 $L$ 是两输入长度的较小值。

本题卷积长度只有 $O(n)$。采用更宽松的统一上界 $L<2^{23}$、$M\le10^9+7$ 时仍小于 $8.4\times10^{24}$，而三个素数乘积约为 $5.95\times10^{25}$，恢复唯一。实际单轴长度也在各辅助素数支持范围内。CRT 按两步 Garner 形式取模，不把三个素数乘积塞入 64 位整数。

由于 $n+1\le1001<10^8\le M$ 且 $M$ 为质数，全部阶乘分母可逆。输入中的质数条件由校验器实际验证。所有模乘先提升为 64 位，三项以上连乘逐步取模。

## 5. 复杂度与验证

采用字 RAM 与本范围下常数代价的模运算；设长度 $k$ 的乘法耗时 $\mu(k)$。建表 $O(n^2)$，平移和卷积共 $O(n\mu(n))$，$n$ 行多点求值共 $O(n\mu(n)\log(n+1))$。以 NTT/CRT 实现 $\mu(n)=O(n\log(n+1))$，合计

$$O(n^2\log^2(n+1))\text{ 时间},\qquad O(n^2)\text{ 空间}.$$

输出本身有 $n^2$ 个整数，所以有 $\Omega(n^2)$ 的显式输出下界；本算法仍有对数因子，不应写成已经证明的 $O(n^2)$ 或全局最优。

参考程序独立使用朴素平移、乘法与 Horner，耗时 $O(n^3)$；暴力程序直接枚举排列。新标程实际与 $n\le9$、三个合法模数下的暴力结果比较，并对中等规模与参考程序比较。全部正式矩阵的每一行、每一列之和都与独立 Eulerian 递推核对，所有元素和随之为 $n!$。不能将矩阵对称作为不变量：联合分布一般不对称。准确执行范围、sanitizer 与逐点计时见 `records/`。
