01 / Benchmark

Performance reasoning,
not pattern recall.

Competitive programming benchmarks usually ask whether a model can recover any accepted solution. AlgoScale asks a sharper question: can it recognize when the familiar complexity no longer fits and construct a genuinely faster algorithm?

Each task preserves the original problem semantics while revising the scale. The release records the source problem, original complexity, new target complexity, and an executable UOJ judging package.

04 / Protocol

From source problem
to executable evidence.

Every result ends at the judge. Generated explanations are never used as correctness evidence.

  1. 01

    Trace the source

    Record the original statement, platform, constraints, reference implementation, and expected complexity.

  2. 02

    Raise the scale

    Change the data regime so that the original asymptotic solution no longer passes while problem semantics remain intact.

  3. 03

    Rebuild the judge package

    Ship tests, validators, checkers, limits, and the new reference solution as a versioned UOJ package.

  4. 04

    Evaluate both modes

    Run direct generation and Harbor-based agents under frozen prompts, budgets, tool policies, and fail-first judging.

Judge

UOJ-native

Compilation, sandboxing, interactive protocols, validators, and checkers run in the same executable environment.

Execution

Harbor-ready

Agent tasks expose only the statement and workspace instructions. Reference solutions and hidden tests stay outside the agent container.
